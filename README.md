# DragonRPA Skelton

> **"골격은 외형이 아니다. 어떻게 서 있는가의 원리다."**

---

## 이 레포지터리에 대하여

이것은 DragonRPA의 기술 스택이나 코드베이스가 아닙니다.

이것은 **회사가 사고하는 방식의 기록**입니다.

개별 프로젝트는 각자의 목표, 생산성, 수익을 추구합니다.
그러나 이 레포지터리는 그 모든 프로젝트의 아래에서 작동하는
**불변의 골격(Skeleton)**을 담습니다.

---

## 사이클: 발상 → 계획 → 경험 → 후회 → (다음 발상)

```
        발상 (IDEA)
       ↗           ↘
  후회                계획
  (REGRET)         (PLAN)
       ↖           ↙
        경험 (EXPERIENCE)
```

이 사이클은 끝나지 않습니다.
후회는 실패의 기록이 아닙니다 — 다음 발상의 연료입니다.
경험은 성공의 증명이 아닙니다 — 우리가 실제로 무엇을 했는가의 기록입니다.
계획은 의도의 선언이고, 발상은 그 모든 것의 시작점입니다.

---

## 디렉토리 구조

```
skelton/
├── 발상/          # 아이디어의 탄생 — 왜 이것을 하려 했는가
├── 계획/          # 의도의 선언 — 어떻게 하려 했는가
├── 경험/          # 실제로 일어난 것 — 무엇을 배웠는가
└── 후회/          # 솔직한 회고 — 다시 한다면 무엇을 다르게 하겠는가
```

## 파일 명명 규칙

```
YYYY-MM_주제명.md
예: 2026-08_AI분석파이프라인_발상.md
```

---

## 이 레포지터리의 독자

- 현재의 나 — 지금 어디에 있는지 확인하기 위해
- 미래의 나 — 과거가 어떻게 현재를 만들었는지 이해하기 위해
- 우리 팀 — 왜 이 방식으로 일하는지 알기 위해

---

*이 골격은 살아있습니다. 경험이 쌓일수록, 후회가 쌓일수록 더 단단해집니다.*

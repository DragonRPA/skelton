# 제품 모델 상세(제원 원장) [제원표 그래픽] 및 [수정] 버튼 위치 재배치

- **일시**: 2026-09-05 15:20
- **버전**: v1.4.0.Build.174
- **카테고리**: 🔬 경험 (EXPERIENCE)
- **도메인**: 제품 모델 관리 / UI 컴포넌트 구조화 (헌장 1.1, 3.1, 3.6)

---

## 1. 배경 및 문제 의식
- 제품 모델 관리(`src/pages/Products.tsx`)의 우측 서랍(Drawer)에서 제원 상세 정보를 확인할 때, 상단 서랍 헤더에 `[제원표 그래픽]`과 `[수정]` 버튼이 위치해 있었음.
- 하지만 서랍 내부는 1. 실물 자산 현황, 2. R2 클라우드 문서함, 3. 상세 물리 제원 규격으로 명확히 구획되어 있으며, 2번 문서함의 경우 `[문서 업로드]` 버튼이 해당 섹션 헤더 우측에 인라인으로 깔끔하게 배치되어 있었음.
- 상단 헤더에 제원 수정 버튼이 몰려 있으면 실무자가 어떤 영역을 수정하는지 직관성이 떨어지고, 상단 헤더가 혼잡해지는 문제가 있었음.

---

## 2. 조치 및 개선 내용
1. **서랍 상단 헤더 슬림화**:
   - 상단 헤더 우측의 `[제원표 그래픽]` 및 `[수정]` 버튼을 제거하고, 모델명/사용배지와 닫기(`X`) 버튼만 남겨 시각적 안정감을 확보.
2. **`3. 상세 물리 제원 규격` 섹션 헤더 우측으로 일원화 배치**:
   - 섹션 헤더를 `justify-content: space-between` Flex 컨테이너로 구조화.
   - 좌측에 타이틀(`3. 상세 물리 제원 규격`), 우측에 `[제원표 그래픽]` 및 `[수정]` 버튼 배치.
   - 편집 모드(`isEditing`) 전환 시 `[저장]`과 `[취소]` 버튼 역시 동일한 섹션 우측 위치에서 자연스럽게 작동하도록 통일.

---

## 3. 실무 효익
- 각 섹션(문서함, 물리제원)의 액션 버튼이 해당 섹션 헤더 우측에 1:1로 일관되게 배치되어 인지 동선(Cognitive Flow)이 자연스러워짐.
- 불필요한 서랍 상단 헤더의 복잡도를 제거하고 전문적이고 깔끔한 UI 레이아웃 완성.

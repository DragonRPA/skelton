## 1. 배경 및 문제의 본질
신규 장비가 대량 입고될 때(예: 동일 모델 S-0808 5대 일괄 취득), 실무자는 동일한 모델과 취득가를 매번 타이핑하지 않고 슬롯을 추가하여 일괄 등록하기를 원합니다.
기존 시스템에는 다음과 같은 4대 비효율 및 결함이 존재했습니다:
1. **모델 및 취득가 미상속**: 슬롯 추가 시 메인 폼의 모델명과 취득가가 자동 연동되지 않아 중복 입력이 필요함.
2. **관리번호 채번 모순**: 슬롯 번호를 계산할 때 기존 슬롯들의 번호를 고려하지 않고 DB의 최신 번호만 조회하여, 슬롯마다 동일한 번호가 추천되거나 메인 번호와 중복되는 결함 발생.
3. **슬롯별 채번 번호 식별 불가**: 슬롯 UI에 헤더나 강조 배지가 없어 어떤 슬롯이 어떤 관리번호인지 한눈에 파악하기 어려움.
4. **내용월수 기준 불일치**: 고소작업대 세법상 기준 내용연수(8년 = 96개월)가 아닌 60개월로 하드코딩되어 감가상각 시뮬레이션 및 DB 저장이 왜곡됨.

## 2. 핵심 해결책 및 설계 결정

### 2.1 메인 모델 & 취득가 100% 자동 상속 및 양방향 동기화
- 슬롯 추가 시 메인 폼의 `singleModelName`과 `singleAcqPrice`가 슬롯에 즉시 자동 주입.
- 메인 폼에서 모델이나 취득가를 변경할 때 기존 슬롯들도 즉시 일괄 동기화되어 담당자의 조작 노력을 최소화 (헌장 1.1).
- 슬롯 행에 `[모델: S-0808]` 배지와 취득가 인풋을 배치하여 동일 모델임을 직관적으로 확인.

### 2.2 슬롯별 순차 관리번호 자동 채번 및 강조 표기 (`getNextSequentialAssetNo`)
- 기존 DB 자산번호 + 메인 폼 자산번호 + 슬롯 번호들을 종합 대조하는 정밀 파싱 알고리즘 탑재.
- 메인 번호가 `KL-0850`이면, 슬롯 추가 시 `KL-0851`, `KL-0852`, `KL-0853` 등 순차 자동 채번.
- 슬롯 목록 상단에 `[순번] [채번 관리번호] [등록 모델] [제조번호(S/N)] [취득원가] [삭제]` 정돈된 그리드 헤더 구축.
- 채번된 관리번호를 파란색 굵은 텍스트 배지 및 편집 가능한 인풋 필드로 명확히 표시.
- `[관리번호 순차 재정렬]` 원클릭 버튼을 탑재하여 메인 번호 변경 시 전체 슬롯 재정렬 지원.

### 2.3 감가상각 내용월수 96개월(8년) 전사 단일 표준화
- `singleDepMonths` 기본값을 96으로 설정.
- 감가상각 시뮬레이션, 엑셀 템플릿 샘플, 엑셀 파싱 엔진, `AppContext`의 `acquireAsset` 및 `batchAcquireAssets` 전반에 96개월 단일 표준 적용.

## 3. 교훈 및 재발 방지 원칙
1. **일괄 입력 워크벤치의 상속 원칙**: 동일 모델 다건 입력 시, 공통 속성(모델, 취득원가, 내용연수 등)은 첫 1회 입력으로 모든 하위 슬롯에 100% 자동 상속되어야 하며, 메인 속성 변경 시 하위 슬롯도 유연하게 동기화되어야 실무자의 실수를 방지한다.
2. **연속 채번 시 메모리 상태 누적 대조**: 채번 로직은 영구 저장된 DB뿐만 아니라 현재 폼(메모리)에 입력 중인 직전 슬롯 번호까지 누적 추적하여 중복 없는 완벽한 순차 번호를 발행해야 한다.

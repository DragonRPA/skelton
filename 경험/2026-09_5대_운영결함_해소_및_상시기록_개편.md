## 1. 달성 성과 (Key Achievements)

1. **상시 매크로 기록 지원 및 툴바 간소화**:
   - 작업자가 굳이 토글하지 않아도 F3~F11 단축키 및 도구 버튼으로 즉시 스텝을 추가할 수 있는 상시 기록 체계 확립.
   - 툴바 1열에서 불필요한 `[기록 시작 (F12)]` 버튼을 제거하고 재생/정지/파일 조작 버튼을 쾌적하게 정돈.

2. **네트워크 자동설정 전용 툴바 버튼 (`IDC_BTN_NETWORK_SETTING`) 신설**:
   - 툴바 2열에 `[네트워크설정]` 버튼을 신설하여 우클릭 없이 원클릭으로 고정IP, DNS, Wi-Fi 주입 스텝 등록 지원.
   - 하위 네트워크 작업 단계마다 중지 플래그 검사를 추가하여 안정성 극대화.

3. **Windows 10/11 윈도우 비밀번호 자동로그인 100% 정상화**:
   - 64비트 레지스트리 뷰(`KEY_WOW64_64KEY`) 강제 적용.
   - 윈도우 재부팅 및 잠금 시 자동 초기화를 방지하는 `ForceAutoLogon = "1"` 추가.
   - 로컬 계정에 대해 도메인 키를 삭제하던 오류를 수정하고 `DefaultDomainName = "."` (로컬 머신) 명시 주입.
   - Windows 11/10 20H2+의 Windows Hello 암호 없는 로그인 차단 정책(`DevicePasswordLessBuildVersion = 0`) 자동 해제.
   - 윈도우 계정/비밀번호 템플릿(`{win_pw}`, `{password}`) 실시간 해석 반영.

4. **작업 스케줄러(`schtasks`) 기반 관리자 권한 UAC 우회 부팅 자동실행 & 시나리오 복원**:
   - 관리자 권한 앱이 윈도우 탐색기 `Run`/`RunOnce`에서 무음 차단(Suppress)되는 윈도우 OS 한계를 돌파하기 위해 `schtasks /Create /TN "HanWhaPCSetupResume" /SC ONLOGON /RL HIGHEST /F` 스케줄러 자동 등록 도입.
   - 재부팅 직전 메모리 상의 시나리오를 디스크(`g_scenario.current_file_path`) 및 복구 스냅샷(`_Ref\macro_resume_state.json`)에 강제 동기화.
   - `config.json`에 `last_scenario_path`를 기억하여 재부팅 후 또는 프로그램 재실행 시 마지막 작업 스크립트로 100% 자동 복구 및 다음 페이즈 자동 재생 연동.

5. **0초 반응형 매크로 정지 (`Macro_ResponsiveSleep`)**:
   - 단일 대형 `Sleep`을 50ms 단위 반응형 루프로 분할하여 사용자가 [정지] 버튼을 누르는 즉시 루프 탈출.
   - 외부 API 블로킹 시 250ms 타임아웃 후 스레드 강제 회수로 즉각적인 정지 보장.

6. **화면 캡처 전 노란색 테두리 강제 소거 (`Vision_ClearHighlight`)**:
   - `Vision_CaptureScreen()` 최우선 순위에서 `Vision_ClearHighlight()`를 호출하여 화면 캡처 시 노란색 테두리가 촬영되는 문제를 원천 차단.
   - 테두리 표시 시간을 400ms로 경량화하고 매 스텝 실행 직전 테두리 자동 소거.

## 2. 배운 점 및 핵심 경험 (Key Lessons Learned)

- **Windows UAC & 관리자 권한 앱의 부팅 자동실행 (Elevation Ergonomics)**:
  - `requireAdministrator` 매니페스트가 선언된 실행 파일은 `HKCU\...\Run` 또는 `RunOnce`로 등록해도 윈도우 로그인 시 무음으로 무시됨.
  - 관리자 권한 자동실행에는 마이크로소프트 공식 승인 규격인 `schtasks /RL HIGHEST /SC ONLOGON`을 사용하는 것이 유일하고 완벽한 해법임.
- **화면 캡처와 UI 하이라이트 오버레이의 상호 간섭 차단**:
  - 화면을 캡처하여 이미지를 탐색하는 비전 RPA에서 시각 피드백 오버레이 창은 반드시 캡처 DC 생성 전에 완벽히 닫혀 있거나 감춰져야 함.

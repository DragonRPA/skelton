# 경험: UI 컨트롤 겹침 100% 해소 및 2단 분할 초깔끔 전문가용 UI 전면 개편

- **일시**: 2026-08-30 16:45
- **연결 발상**: [2026-08_UIA_기반_초고속_비전하이브리드_자동화.md](../발상/2026-08_UIA_기반_초고속_비전하이브리드_자동화.md)
- **연결 계획**: [2026-08_UIA_요소_저장소_및_목록_관리_구축.md](../계획/2026-08_UIA_요소_저장소_및_목록_관리_구축.md)
- **맥락**: 기능 확장으로 인해 좌측 패널(시스템 설정, 실시간 마우스 인스펙터, 이미지 프리뷰)과 상단 툴바(액션, 비전, UIA)의 컨트롤들이 서로 겹치고 복잡해지던 UI 결함을 2단 콤팩트 그리드와 반응형 3단 툴바로 전면 재정돈.

---

## 1. 달성 성과 (Key Achievements)

1. **좌측 패널 겹침 100% 해소 (2단 콤팩트 그리드)**:
   - ID/PW, 사번/이름, 기본DNS/보조DNS, 윈도우계정/비번 등 연관 필드를 1행 2열로 콤팩트하게 묶어 그룹 높이를 554px ➔ 366px로 최적화.
   - Group 1과 Group 2(실시간 인스펙터) 간 충돌/오버랩 0건 달성.

2. **실시간 인스펙터 대형 고해상도 프리뷰 박스 탑재 (310x246)**:
   - 기존 68px 수준의 좁은 썸네일 박스를 246px 대형 뷰어로 확장하여, 탐색 중인 템플릿 이미지의 모양과 텍스트를 작업자가 즉시 선명하게 식별 가능.

3. **상단 툴바 3단 정돈 및 우측 리스트뷰 반응형 레이아웃**:
   - 메인 액션(Row 1), 비전/일반 스텝(Row 2), UIA 전용 도구(Row 3)를 기능별로 명확히 분리.
   - 창 크기 조절 시 리스트뷰 폭과 높이가 자동으로 늘어나는 반응형 `WM_SIZE` 핸들러 연동.

---

## 2. 배운 점 및 핵심 경험 (Key Lessons Learned)

- **정보 밀도와 여백의 균형 (Information Density vs Spacing)**:
  - 무조건 세로로 컨트롤을 나열하면 필연적으로 세로 스크롤이나 하단 그룹과의 충돌이 발생함.
  - 연관된 짧은 입력창(ID/PW, IP/Port, 계정/비번)을 가로 2열 콤팩트 그리드로 묶는 설계가 가독성과 공간 효율성을 동시에 극대화함.

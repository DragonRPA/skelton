# 당사자산 취득 절차 고밀도 대장 및 감사 증빙 체계 구축

- **기록일시**: 2026-09-03 20:00
- **프로젝트**: 기연리프트 ERP 시스템 (`Kiyuen_Lift`)
- **버전**: `v1.3.0.Build.84`

---

## 1. 맥락 (Context)
- 렌탈 장비 ERP에서 자산 대장의 출발점인 '당사자산 취득 / 매각' 메뉴가 기존에는 단순 입력 폼만 제공되어, 취득 후 화면에서 데이터가 사라지고 기존 취득/매각 내역을 대조할 수 없는 심각한 정보 단절 문제가 있었음.
- "당사자산 취득 절차에서 고려해야 할 핵심 정보와 현재 구현 수준을 검증하고, 사용자 입력 편의성과 감사 증거 확보를 고려하여 메뉴 흐름과 UIUX를 개편하라"는 사장님 지시에 따라 전면 개편을 집행함.

---

## 2. 핵심 발견 및 해결 (Key Findings & Resolution)
1. **고밀도 대장 그리드(Inspection Body) 결여 해소**:
   - 텅 빈 폼 카드 화면을 `[당사자산 취득 대장]` 및 `[자산 매각 처분 대장]` 2대 서브탭과 화면 세로 80%를 점유하는 고밀도 테이블(행 높이 38px)로 전면 전환함.
2. **3-Way 초고속 취득 파이프라인 탑재**:
   - **단건 등록**: 모델 선택 시 제조사/제원 자동 상속 + 모델별 기존 번호 분석 기반 다음 관리번호 자동 추천 (`suggestNextAssetNo`).
   - **연속 N대 일괄 생성기 (Batch Generator)**: 시작 번호(예: `SJ19-106`) 및 수량(예: 5대) 입력 시 5개 슬롯 실시간 미리보기 및 차대번호 인라인 입력, 1-클릭 일괄 취득 지원.
   - **엑셀 표준 양식 다운로드 및 일괄 업로드**: 표준 서식 제공, 중복 번호 실시간 사전 검증, 유효 데이터 일괄 취득 확정.
3. **감사 증거 확보 체계 구축 (Audit Evidence Trail)**:
   - 매입처 마스터(`vendors`) 1:1 매핑 + 안전인증/검사증명서 URL 저장.
   - 대장 행 클릭 시 우측 슬라이드오버 Dossier 패널 표출 (물리 제원, 감가상각 원장, 안전 증빙 링크, 자산 감사 로그 타임라인).
   - 취득 확정 시 `asset_in_out_logs`에 `type: 'ACQUISITION'`으로 감사 로그 무누락 자동 적재 (헌장 1.2 준수).
4. **Gutenberg Z-패턴 및 최하단 회계 대차대조 검증 바 완결 (헌장 3.5)**:
   - 취득 대장: `총 취득원가 = 현재 장부가 + 감가상각누계액 | 대차 차액 ₩0`
   - 매각 대장: `총 매각대금 = 장부가 총액 + 처분손익 | 대차 차액 ₩0`

---

## 3. 체득 원칙 (Core Principles Learned)
- **자산 등록 메뉴는 반드시 '대장(Ledger)'이 기본 작업대여야 한다**: 등록 폼만 있는 화면은 업무 연속성을 파괴함. 작업자가 자신이 무엇을 입력했고 전체 현황이 어떻게 변했는지를 동일 화면에서 실시간 조망할 수 있어야 비로소 완성된 전문 시스템이다.
- **다수 장비 도입 업무는 N대 연속 배치 제너레이터가 필수적이다**: 동일 모델 5대, 10대 도입 시 단건 반복 입력을 강제하지 않고 시작번호와 수량으로 1-클릭 생성하는 것이 헌장 1.1 "최소 노력으로 최대 효익"의 표본이다.

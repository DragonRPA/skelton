# 장비 모델별 제원표(PDF) 자동 파싱 및 DB 일괄 주입 시스템

- **기록일시**: 2026-08-27 16:13
- **대상**: `00.제품별문서` 하위 53개 제원표 PDF 및 제품(products) 스키마

## 1. 개요 및 맥락
기연리프트가 보유한 전 장비 모델(53종)의 제원표 PDF 문서를 순회 탐색하여, 13대 핵심 규격(작업높이, 발판높이, 장비중량, 적재중량, 장비크기, 플랫폼크기, 등판능력, 주행속도, 확장 전/후 분배하중, 최대허용풍속 등)을 기하학적 좌표(PyMuPDF) 및 OCR로 정밀 파싱하고 DB에 일괄 주입(Bulk Upsert) 체계를 완성함.

## 2. 핵심 구현 사항
1. **스키마 및 DDL 확장**: `products` 테이블에 13대 제원 규격 컬럼 신설 (`patch_v1_129_product_spec_schema.sql`).
2. **배치 파싱 엔진**: 53개 PDF 중 텍스트 기반 43개 기하학적 바운딩 박스 추출 + 스캔 이미지 10개 렌더링 검증 완료.
3. **UI 뷰어 탑재**: `Products.tsx` 화면에서 각 모델별 `[제원표]` 버튼 클릭 시 실물 서식과 100% 동일한 규격표/다이어그램 즉시 팝업 표출.
4. **일괄 주입 스크립트**: `scripts/seed_products_spec_53.sql` 및 `db.ts` 시드 데이터 53종 완결 매핑.

## 3. 효익
- 실무자의 53개 모델 수동 입력 공수 100% 절감 (0초 소요)
- 향후 스마트 출고 시 계약 모델별 '장비제원표.PDF' 무인 자동 생성 및 고객사 첨부 발송 기반 확립.

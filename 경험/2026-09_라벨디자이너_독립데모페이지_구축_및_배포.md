# [경험 자산] 라벨 디자이너 독립 데모 페이지(/demo) 구축 및 배포

- **일자**: 2026-09-26
- **프로젝트**: `LabelPrintStation`
- **작성자**: DragonRPA 시스템 개발팀

---

## 1. 개요 및 목적
라벨스테이션의 핵심 기능인 **라벨 디자이너(WYSIWYG 캔버스, 실시간 ZPL 컴파일, 가상 인쇄 시뮬레이터)**만을 백엔드 DB 연결 및 로컬 에이전트 없이 웹 브라우저에서 즉시 체험할 수 있도록 독립형 데모 페이지(`https://www.dragonrpa.co.kr/LabelPrintStation/demo`)로 구축 및 배포함.

---

## 2. 주요 구현 내용

### 2.1 모의(Mock) 프린터 및 4대 비즈니스 도메인 스키마 내장
- **모의 프린터 4종**:
  - Zebra ZT411 (203dpi/8dpmm 산업용)
  - Zebra GK420d (203dpi/8dpmm 데스크톱)
  - Zebra ZD420 (300dpi/12dpmm 고해상도)
  - 가상 라벨 에뮬레이터 (Virtual PDF/ZPL)
- **모의 스키마 4종 및 샘플 데이터 실시간 바인딩**:
  1. `asset` (자산 관리: 자산번호, 모델명, 시리얼, MAC, IMEI, 교정일자 등)
  2. `logistics` (물류/택배 송장: 송장번호, 수취인, 배송지, 취급주의 등)
  3. `parts` (제조/자재 부품: 부품코드, 품명, LOT번호, 입고수량 등)
  4. `medical` (의료/시약 검체: 검체번호, 환자코드, 보관조건, 유효기한 등)

### 2.2 핵심 디자이너 기능 강조
- **WYSIWYG 비주얼 캔버스**: 텍스트, Code128 바코드, 2D QR코드, 박스, 선 자유 드래그 앤 드롭 이동 및 실시간 속성 편집
- **6대 업종별 프리셋 기본 탑재**: 표준 자산 라벨, 소형 QR 라벨, 물류 송장, 부품 식별표, 의료 검체, 통신장비
- **실시간 Zebra ZPL II 프로그래밍 코드 컴파일러 & 1클릭 복사**
- **가상 인쇄 시뮬레이터 (Virtual Print Simulator)**: 물리 프린터 없이도 출력 결과 즉시 모의 시뮬레이션
- **서식 JSON 파일 내보내기/저장**

### 2.3 무결한 배포 라우팅 아키텍처
- `https://www.dragonrpa.co.kr/LabelPrintStation/demo` 접근 시 Vercel/Next.js 및 GitHub Pages SPA 라우터를 통해 404 없이 0.01초 만에 데모 페이지로 직통 렌더링.

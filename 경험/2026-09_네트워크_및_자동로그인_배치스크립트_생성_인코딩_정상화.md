# 경험: 네트워크 및 자동로그인 배치 스크립트 생성 인코딩/기능 정상화

- **연결 계획**: [2026-08_UIA_요소_저장소_및_목록_관리_구축.md](../계획/2026-08_UIA_요소_저장소_및_목록_관리_구축.md)
- **맥락**: 환경설정 탭의 `[네트워크 스크립트 생성]` 버튼 클릭 시 생성되는 `network_setup.bat` 파일이 한 줄의 깨진 문자열(`echo [netsh interface ipv4 set address name="...`)로 잘려 나오는 치명적 결함을 긴급 해결함. MSVC C 런타임의 기본 C 로케일 하에서 `fwprintf`가 한글 유니코드 변환에 실패하여 개행과 인자를 모두 누락시키고 중단되던 원인을 규명하고, UTF-8 BOM 바이너리 직렬화와 완전한 무선/유선 동적 감지 파이프라인으로 전면 개편함.

---

## 1. 결함의 근본 원인 (Root Cause Analysis)

1. **CRT 기본 C 로케일 하에서의 `fwprintf` 비ASCII 한글 변환 실패**:
   - `_wfopen_s(&fp, bat_path, L"w")`로 텍스트 모드로 파일을 열고 `fwprintf`로 한글(`[네트워크...]`, `이더넷`)을 출력할 때, C 런타임의 기본 로케일이 `C`이므로 0x7F를 초과하는 한글 문자를 만나는 즉시 문자열 변환이 실패(`EILSEQ`)하여 스트림 에러 플래그가 설정되고 출력이 중단됨.
   - 라인 끝의 개행 문자(`\n`)와 뒤따르는 서식 인자가 모두 출력되지 못하고 다음 `fwprintf` 호출이 같은 라인에 덧붙여지면서 `echo [netsh interface ipv4 set address name="netsh interface ipv4 set dns name="...` 형태로 1줄 압축 깨짐 현상 발생.

2. **단순 `이더넷` 하드코딩 및 Wi-Fi 프로필/MAC 무작위화 파이프라인 부재**:
   - 노트북이나 Wi-Fi 환경에서 무선 랜 어댑터명이 `Wi-Fi` 또는 고유명으로 되어 있을 때 `이더넷` 하드코딩 명령은 100% 실패함.
   - 기존 파이썬 버전 및 매뉴얼 규격에 정의된 Wi-Fi 프로필 등록(`netsh wlan add profile`), MAC 무작위화 ON/OFF 분기, 동적 어댑터 탐색 파이프라인이 C 버전에 온전히 이식되지 않았음.

## 2. 해결 및 달성 성과 (Key Achievements)

1. **UTF-8 BOM 바이너리 직렬화 파이프라인 (`WriteUtf8FileWithBom`) 구축**:
   - 파일을 바이너리(`L"wb"`) 모드로 열고 UTF-8 BOM(`0xEF, 0xBB, 0xBF`) 3바이트를 선두에 기록.
   - `WideCharToMultiByte(CP_UTF8, ...)`를 통해 완성된 유니코드 배치 스크립트 전체를 100% 무결한 UTF-8 바이트로 일괄 변환 후 `fwrite`로 원자적 저장.
   - 메모장(Notepad), Windows 터미널, `cmd.exe` 어디에서 열어도 한글 주석과 명령어가 1바이트의 깨짐이나 누락 없이 완벽 렌더링됨.

2. **완전한 3단계 배포용 네트워크 스크립트 3종 생성 지원**:
   - **`network_setup.bat`**: 기본 메인 배치 (고정 IP 환경 권장, MAC 무작위화 비활성).
   - **`network_setup_{SSID}_mac_off.bat`**: 고정 IP 환경 전용 (MAC 무작위화 OFF).
   - **`network_setup_{SSID}_mac_on.bat`**: 프라이버시 모드 (MAC 무작위화 ON).
   - 관리자 권한 자동 검증(`cacls.exe`), Wi-Fi 프로필 등록, 연결 명령, PowerShell 기반 무선 어댑터(`Native 802.11`) ➔ 활성 어댑터(`Status -eq 'Up'`) ➔ 기본 어댑터(`이더넷`) 3단계 안전 폴백 적용.

3. **자동로그인 스크립트(`set_auto_logon.bat` / `autologon_setup.bat`) 동반 현대화**:
   - 자체 관리자 권한 UAC 승격 스크립트 내장.
   - [1] 자동로그인 활성화 / [2] 자동로그인 비활성화 대화형 CLI 메뉴 지원.
   - `ForceAutoLogon`, 로컬 도메인(`.`), Windows Hello 암호 없는 로그인 차단 해제 정책 자동 주입.

---

## 3. 배운 점 (Key Lessons Learned)

- **Win32 C 파일 I/O에서 한글 텍스트 저장 시 `fwprintf` 절대 지양**:
  - Windows C/C++ 개발 시 텍스트 파일에 다국어/한글을 기록할 때는 CRT 로케일에 의존하는 `fwprintf`나 `fputs`를 쓰지 말고, 항상 `WideCharToMultiByte(CP_UTF8, ...)` + `fwrite` (UTF-8 BOM 포함) 조합을 단일 표준으로 강제해야 함.

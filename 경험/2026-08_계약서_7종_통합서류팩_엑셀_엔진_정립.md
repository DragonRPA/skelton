# [경험] 계약서 7종 통합 서류팩 정품 엑셀 COM 파이프라인 정립

- **작성일자**: 2026-08-29 16:35
- **관련 프로젝트**: (주)기연리프트 ERP (`Kiyuen_Lift`)
- **주제**: 가상 HTML 캔버스 캡처 방식 폐기 및 정품 엑셀 COM 엔진 단일 표준화

---

## 1. 배경 및 문제 의식
* 고객사 계약 체결 시 현장 반입에 필요한 7종 서류(계약서, 체크리스트, 점검표, 모델별 정규문서, 보험증권, 사업자등록증, 통장사본)를 자동 생성하는 엔진 개발 중,
* 브라우저 DOM 기반 HTML 캔버스 캡처(`html2canvas`) 방식 적용 시 데이터 바인딩 유실, 스타일 깨짐, 폰트 번짐, 백지 출력 등의 치명적 결함이 확인됨.

## 2. 핵심 깨달음 및 아키텍처 정립
1. **정품 엑셀 COM 파이프라인 단일 표준화**:
   * Cloudflare R2에서 동기화된 로컬 정품 엑셀 서식(`01.계약서.xlsx`, `02.반입전체크리스트.xlsx`, `03.안전점검결과서.xlsx`, `04.제원표양식.xlsx`)을 Windows 엑셀 엔진으로 열어 태그를 치환하고 `Microsoft Print to PDF`로 출력하는 정통 방식만이 100% 무결점 인쇄 품질을 보장함.
2. **다중 자산($N$대) 배치 루프 처리**:
   * 12대 자산 투입 시 체크리스트 12장, 점검표 12장을 엑셀에서 각각 루프 출력하여 $1 + 12 + 12 = 25$페이지의 실물 PDF를 생성.
3. **제원표 라이프사이클 트리거 엄격 분리**:
   * 제원표 엑셀 기본양식은 **오로지 제품관리에서 스펙 저장 시 1회만 작동**하여 `제원표.pdf`를 생성·보관하고,
   * **계약관리에서는 기 작성된 PDF를 무연산 고속 병합**하여 속도와 데이터 정합성(SSOT)을 극대화함.

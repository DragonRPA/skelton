## 1. 개요 및 배경
- 매뉴얼 스튜디오는 단순 캡처 도구를 넘어, 사내외 임직원의 매뉴얼 저작 노력 대비 효과와 편익을 극대화하는 **올인원 전문가용 매뉴얼 제작 솔루션**으로 진화하고 있다.
- 사용자 요청에 따라 체계적으로 수립된 **4-Phase 로드맵**을 단계별(Phase 1 -> 2 -> 3 -> 4)로 차질 없이 완결하고, 13개 글로벌 언어 i18n 무누락 등록 및 67개 전 단위 테스트 100% 통과로 단일 통합 바이너리 배포 준비를 완료했다.

## 2. 4대 마일스톤 핵심 성과

### Phase 1: Visual & Office Foundation (시각 및 오피스 기반)
1. **어도비 CC 스타일 Ms 모노그램 아이콘 정식 배포**:
   - ssets/manual_studio.ico 7대 멀티 해상도(16~256px) 밉맵 적용, 작업표시줄 및 바탕화면 바로가기 최신화.
2. **모던 윈도우 창틀 & 소프트 섀도우**:
   - Notion/Apple 스타일 3색 신호등 버튼(🔴🟡🟢) + 12px 둥근 모서리 + 20px 가우시안 드롭 섀도우를 기본값(ON)으로 적용. 툴바 원클릭 토글 지원.
3. **한컴 한글(HWP) COM 직결 내보내기**:
   - 브라우저 개발자 도구(F12) 충돌을 방지하기 위해 글로벌 단축키 Shift+F10, 스튜디오 로컬 단축키 F12 이원화.
   - 한글 커서 위치에 표 및 규격화된 이미지 중앙 정렬 자동 안착.
4. **하단 다단계 타임라인 스토리보드 필름스트립**:
   - 가로 스크롤 카드 도크로 원클릭 단계 전환, 스텝 복제/이동/삭제 및 [전체 PPT 전송], [전체 한글 전송] 원스톱 자동화.

### Phase 2: Packaging & Animation (출판 및 애니메이션)
1. **반응형 단일 파일 HTML5 자가완비형 웹북**:
   - 외부 CDN/로컬 폴더 의존성 0% 단일 .html 파일. Base64 이미지 인라인 임베딩, 좌측 목차, 실시간 검색 필터, 확대 라이트박스, 다크/라이트 테마, @media print 완비.
2. **초경량 애니메이션 GIF 튜토리얼 생성기**:
   - 스토리보드 스텝들을 1.5초 루핑 GIF로 일괄 변환. 노션, 슬랙, 메신저 업로드 최적화.

### Phase 3: Intelligent Processing & Security (지능형 보안 및 정제)
1. **6대 개인정보 자동 마스킹 (Shift+M)**:
   - 전화번호, 주민번호, 이메일, 계좌번호, 카드번호, IP 주소를 WinRT OCR 바운딩 박스 기반으로 자동 탐지하여 BlurMosaicItem 비파괴 일괄 생성. Ctrl+Z 1회 복원.
2. **배경 클린업 스마트 지우개 (X)**:
   - OpenCV Telea/Navier-Stokes 인페인팅 엔진으로 워터마크, 텍스트를 주변 배경 텍스처로 무흔적 소거.

### Phase 4: Next-Gen Capture Automation (차세대 캡처 자동화)
1. **UI 요소 마그네틱 스마트 스냅**:
   - Windows API WindowFromPoint + ChildWindowFromPointEx 계층 순회로 최하단 UI 컨트롤을 실시간 탐색, 형광 시안 점선 가이드 표출 및 단순 클릭 시 100% 자동 채택 캡처 확정. X 키 토글.
2. **파노라마 수직 스크롤 스티칭**:
   - OpenCV 정규화 템플릿 매칭($\ge 0.70$) 기반 수직 오프셋 계산, 중복 영역 절단 및 
p.vstack 무경계선 긴 이미지 합성. 리본 메뉴 및 CLI --cli stitch 완비.
3. **무인 연속 액션 레코더**:
   - 저지연 마우스 클릭 실시간 감지 + 클릭 지점 번호 스탬프 자동 타각 + 스토리보드 스텝 자동 누적. 화면 상단 최상위 반투명 플로팅 컨트롤 바(🔴 REC, N단계, [완료]) 제공.

## 3. 핵심 배운 점 및 인사이트
1. **UI 계층 순회의 한계 극복**:
   - 단일 WindowFromPoint는 최상위 윈도우 핸들만 반환하므로 내부 버튼/입력창을 잡지 못함. ChildWindowFromPointEx와 CWP_SKIPINVISIBLE | CWP_SKIPDISABLED 플래그를 최대 8단계 재귀/루프 순회함으로써 초정밀 마그네틱 스냅을 구현할 수 있었음.
2. **OCR과 보안의 시너지**:
   - OCR은 단순히 텍스트를 추출하는 것을 넘어, 좌표 정보(ounding_rect)를 패턴 매칭과 결합할 때 강력한 '개인정보 자동 마스킹 가디언'으로 진화함.
3. **단축키 충돌 설계 원칙**:
   - 현장 엔지니어가 브라우저에서 작업할 때 F12를 자주 누르므로, 전역 단축키로 F12를 가로채면 치명적인 업무 방해가 됨. 전역은 Shift+F10, 스튜디오 활성 시에는 F12로 스코프를 분리하는 이원화 정책이 최적의 사용자 경험을 창출함.

# 2026-09 국내/해외 통합 결제 및 멀티 프로덕트 라이선스 무인 자동화 시스템 구축 완결

## 1. 개요 및 배경
- **목적**: `www.dragonrpa.co.kr`에서 **매뉴얼 스튜디오(Manual Studio)** 및 **라벨스테이션(Label Print Station)** 등 자사 소프트웨어를 국내(원화) 및 전 세계(달러) 고객에게 100% 무인 판매하고, 결제 즉시 암호화 라이선스 키 발급, 7개 언어 실시간 맞춤 이메일 발송, 1PC HWID 노드락 정품 인증, 셀프 키 찾기까지 완결하는 엔터프라이즈 결제/라이선스 아키텍처 구축.
- **적용 대상**: 사내 통합 ERP Neon PostgreSQL DB (`neondb`), Next.js 15 App Router 공식 웹사이트.

---

## 2. 주요 아키텍처 및 구현 내역

### A. 중앙 통합 DB 스키마 (`neondb` / `schema.sql`)
1. **`orders`**: 주문/결제 마스터 (주문번호, 결제게이트웨이 `TOSS`/`LEMONSQUEEZY`/`STRIPE`/`TEST`, 통화 `KRW`/`USD`, 금액, 고객이메일, 국가코드, 언어코드, 상태 `PAID`)
2. **`licenses`**: 라이선스 마스터 (`DRAGON-[PROD]-[PLAN]-[RAND]-[CRC]`, 허용 PC수 `max_activations`, 상태 `ACTIVE`/`REVOKED`/`EXPIRED`, 주문 매핑)
3. **`license_activations`**: PC 하드웨어(CPU/메인보드 HWID) 1PC 노드락 기기 바인딩 및 최종 확인 이력

### B. 암호학적 라이선스 서비스 (`src/lib/licenseService.ts`)
- **포맷**: `DRAGON-MS-PERM-8F92-K3D1-C19A` (제품코드, 플랜코드, 16진 암호난수, CRC16 체크섬)
- **클라이언트 오타 사전 감지**: 클라이언트 단에서 0초 만에 체크섬 검증.
- **노드락 검증 (`verifyLicense`)**:
  - 기존 등록 기기 ➔ `last_check_at` 갱신 및 0.1초 인증 완료
  - 신규 기기 ➔ `currentActivations < maxActivations` 확인 후 슬롯 배정
  - 초과 시 ➔ `MAX_ACTIVATIONS_EXCEEDED` 방어 및 기존 PC 해제 안내

### C. 7개 언어 실시간 맞춤 이메일 발송기 (`src/lib/emailService.ts`)
- **지원 언어**: 한국어(`ko`), 영어(`en`), 일본어(`ja`), 중국어(`zh`), 독일어(`de`), 스페인어(`es`), 프랑스어(`fr`)
- **발신자 명의**: `(주)드래곤알피에이 <license@dragonrpa.co.kr>`
- **트리거**: 결제 승인 0초 즉시 정품 키, 다운로드 링크, 3단계 인증 가이드가 수록된 고품질 반응형 HTML 이메일 자동 발송.

### D. 프론트엔드 및 신규 상용화 랜딩 페이지
1. **통합 결제 모달 (`src/components/PaymentModal.tsx`)**:
   - `🇰🇷 원화 결제(KRW)`: 토스페이먼츠 연동 (카카오/네이버/토스/국내카드)
   - `🌐 글로벌 결제(USD)`: 글로벌 체크아웃 (Apple Pay/Google Pay/해외카드/PayPal)
   - 3초 즉시 모의 결제 & 정품 발급 시뮬레이터 내장
2. **신규 라벨스테이션 공식 랜딩 (`/label-station`)**:
   - 1초 Zebra 고속 출력, 웹 캔버스 디자이너, 엑셀 ERP 자동화 USP 및 상용화 플랜(스탠다드 ₩55,000 / 비즈니스 ₩165,000) 등재
3. **결제 결과 페이지 (`/payment/success`, `/payment/fail`)**:
   - 원클릭 키 복사, 설치 프로그램 다운로드, 3단계 인증 가이드
4. **셀프 라이선스 키 찾기 (`/license-lookup`)**:
   - 이메일 입력 시 보유 중인 모든 소프트웨어 라이선스 목록 조회 및 이메일 0초 자동 재발송

## 3. 엔드포인트 라우팅 명세

| 엔드포인트 | 메서드 | 용도 |
| :--- | :---: | :--- |
| `/api/payments/toss/confirm` | POST | 토스페이먼츠 결제 승인 및 라이선스 발급 |
| `/api/payments/global/webhook` | POST | Lemon Squeezy / Stripe 글로벌 결제 웹훅 처리 |
| `/api/payments/test-checkout` | POST | 0원 모의 결제 & 즉시 라이선스 발급 테스트 |
| `/api/license/verify` | POST | 데스크톱 앱(ManualStudio/LabelStation) HWID 정품 인증 |
| `/api/license/lookup` | POST | 고객 이메일 기준 라이선스 목록 조회 & 자동 재발송 |
| `/label-station` | GET | 라벨스테이션 공식 상용화 랜딩 페이지 |
| `/license-lookup` | GET | 고객 셀프 라이선스 키 찾기 페이지 |
| `/payment/success` | GET | 결제 완료 및 라이선스 키 복사/다운로드 화면 |
| `/payment/fail` | GET | 결제 취소/실패 안내 화면 |

# 은행입출금대장 수납업무 WTT 20건 수행 및 편의기능 개편 경험 리포트

- **일자**: 2026-09-05
- **수행자**: e-Bro 시스템 수석 개발팀
- **버전**: v1.2.9.Build.3

---

## 1. 개요
고소작업대 렌탈 도메인의 핵심 수금 파이프라인인 '은행입출금대장 > 통장 수납 대사'에 대해
전사 표준 헌장 5.5에 의거한 5대 축 교차 결합 20회 도메인 관통 스트레스 테스트(WTT)를 전수 수행함.

## 2. 관통 스트레스 테스트(WTT)를 통해 발굴된 핵심 결함
1. **부가세(VAT) 미반영으로 인한 금액 일치 매칭 무력화 버그**:
   - `totalAmount`(공급가)와 입금액(공급대가 VAT 10% 포함)을 직접 비교하여 정상 입금도 금액 일치 자동 매칭이 100% 무력화되던 버그 발굴 및 수정.
2. **특정 청구서 타겟(Pinpoint) 충당 불가 및 강제 Cascade 결함**:
   - 실무자가 특정 현장(예: 판교테크노)을 콕 집어 선택해도 무조건 과거 미수부터 순차 소진되어 현장별 채권이 왜곡되던 치명적 결함(WTT-BANK-13 FAIL) 적발.
   - `PINPOINT`(단독 충당), `CASCADE`(순차 소진), `MULTI`(다중 배분) 3단 선택권 신설로 완벽 해결.
3. **타행 송금 수수료 500원 차감 시 영구 PARTIAL 고착 결함**:
   - 330,000원 청구에 대해 수수료 500원을 뺀 329,500원 입금 시 영구 미수로 남아 연체 채권으로 오인되던 문제.
   - `[차액 ₩500 송금수수료 자동 감액]` 원클릭 버튼 및 `payments.feeAdjustment` 상계 완납 처리 지원.
4. **사후 일괄 자동 수납(Batch Auto-Match) 파이프라인 부재**:
   - 엑셀 업로드 시점 외에는 일괄 자동 수납이 없어 수십 건을 수동 클릭하던 문제 해결 ➔ `[⚡ 일괄 자동 수납 (N건) ➔]` 신설.
5. **공식 입금표 / 수납 확인서(영수증) 발행 기능 전무**:
   - 건설사 경리팀 제출용 법인 직인 날인 공식 A4 입금표 원클릭 인쇄 뷰어 신설.
6. **UI/UX 헌장 3.6 유형 B 고밀도 슬림 그리드 적용**:
   - 38~42px 슬림 행, 첫 번째 컬럼 Col 0 Sticky 고정(`[수납 ➔]` 버튼 유실 방지), 최하단 Gutenberg 대차대조 바 화면 하단 상시 고정.

## 3. 검증 결과
- WTT 20건 전수 통과 (20/20 ALL PASS, 100%)
- 프로덕션 빌드 0 Error 검증 완료.

# [경험 자산] 라벨프린트스테이션 Neon DB 이전, 쿼리 엔진 고도화 및 도메인 전환

- **일자**: 2026-09-17
- **프로젝트**: `LabelPrintStation` (구 ImageScan)
- **작성자**: DragonRPA 시스템 개발팀

---

## 1. 개요 및 배경

기존 Supabase 백엔드 인프라의 잔재를 완전히 제거하고 Neon Serverless PostgreSQL로 전면 마이그레이션하면서 발생한 쿼리 빌더 호환성 문제, Realtime Mock 채널 라이프사이클 이슈, 그리고 `www.dragonrpa.co.kr` 서브도메인 체계로의 통합 전환을 성공적으로 완결한 기술적 경험을 자산화한다.

---

## 2. 주요 기술적 결함 및 해결 방안

### 2.1 `@neondatabase/serverless` v1.x 함수 호출 규격 불일치
- **문제**: Neon SDK 최신 버전에서 `sql("SELECT...", params)` 일반 함수 형태의 파라미터 전달이 금지되고 태그드 템플릿 또는 `sql.query(query, params)`만 지원되어, 프론트엔드의 모든 동적 쿼리가 런타임 예외를 발생시킴.
- **해결**: `NeonQueryBuilder` 내부 실행기(`_runRaw`)를 `this.sql.query(query, params)`로 표준화하여 SQL 파라미터화 바인딩을 100% 안전하게 정상화.

### 2.2 Postgres 18 `json_populate_recordset` 배치 삽입 표준화
- **문제**: `json_to_recordset`을 사용할 경우 모든 필드가 `text`로 역직렬화되어 UUID, JSONB, TIMESTAMP 컬럼에 INSERT/UPSERT 시 타입 캐스팅 에러(`column "id" is of type uuid but expression is of type text`) 발생.
- **해결**: `json_populate_recordset(null::table_name, $1::json)` 구문을 도입하여 PostgreSQL 엔진이 대상 테이블의 DDL 스키마 타입을 자동 매핑하도록 개선.

### 2.3 Realtime Channel 체이닝 및 언마운트 예외 (`e.unsubscribe is not a function`)
- **문제**: 컴포넌트 마운트 시 `client.channel(...).on(...).subscribe()` 호출 후 언마운트 시 `channel.unsubscribe()`를 실행할 때, 체이닝 단계별 객체 참조 불일치로 `unsubscribe is not a function` 에러가 발생하여 에러 바운더리 화면이 트리거됨.
- **해결**: `createMockChannel`을 구축하여 체이닝의 모든 단계(`.channel()`, `.on()`, `.subscribe()`, `.unsubscribe()`, `.removeChannel()`)에서 항상 자기 자신(Self)을 반환하고 무결한 `unsubscribe` 메소드를 보장.

### 2.4 데이터 조회 동선 최적화 (불필요한 자동 로딩 차단)
- **문제**: 대용량 임시 데이터 탭 진입 시 페이지네이션 루프로 인해 네트워크 지연 및 타임아웃 발생.
- **해결**: 탭 마운트 시의 자동 백엔드 조회를 차단하고 로컬 캐시를 0초 렌더링하며, 사용자가 명시적으로 `[🔍 DB 조회]` 버튼을 누를 때에만 단일 직통 쿼리(`.range(0, 49999)`)로 고속 로딩되도록 전환.

### 2.5 도메인 및 배포 체계 통합
- **도메인**: `https://www.dragonrpa.co.kr/LabelPrintStation/`
- **에이전트**: C# Native 에이전트(`UBUS_DragonRPA_Agent.exe`)의 `FRONTEND_URL` 및 스마트 자가 업데이트 URL을 신규 도메인 경로로 일원화하고 다중 위치(`public/`, `dist/`, `print-agent/dist/`, `E:\`)에 자동 동기화 배포.

## 3. 핵심 성과 및 전사 적용 기준

1. **Zero-Error Fluent Query Builder 확립**: Supabase API 호환 인터페이스(`from`, `select`, `insert`, `upsert`, `update`, `delete`, `eq`, `ilike`, `in`, `or`, `order`, `range`, `single`, `maybeSingle`)를 순수 SQL로 완벽 변환하는 경량 어댑터 확보.
2. **배포 안정성 무결성**: GitHub Pages 기반 CDN 및 C# Windows 데스크톱 에이전트 간의 1:1 통신 및 자동 업데이트 무결성 입증.

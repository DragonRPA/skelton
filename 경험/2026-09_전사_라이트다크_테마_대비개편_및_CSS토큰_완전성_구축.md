# 전사 라이트/다크 테마 대비 전면 개편 및 CSS 토큰 완전성 구축

- **기록일시**: 2026-09-03 19:25
- **프로젝트**: 기연리프트 ERP 시스템 (`Kiyuen_Lift`)
- **버전**: `v1.3.0.Build.83`
- **관련 커밋/이슈**: `E-034`

---

## 1. 맥락 (Context)
- 시스템 화면 전체에서 라이트 모드와 다크 모드 전환 시, 배경색과 상반되는 글자색 설정이 뒤죽박죽되어 텍스트가 사라지거나(어두운 배경에 검은 글씨) 흰색 입력창에 흰 글씨가 표출되는 등 시인성과 가독성이 심각하게 저하되는 현상이 발생함.
- "UI 전체에 밝은 화면과 어두운 화면 모드에서 배경색과 상반되는 글자색 설정이 종종 뒤죽박죽 되는데 재점검하라"는 지시에 따라 전사 컴포넌트 및 CSS 테마 시스템에 대한 원칙론적 전수 정밀 감사를 집행함.

---

## 2. 핵심 발견 및 난관 (Key Findings & Challenges)
1. **정의되지 않은 CSS 토큰 광범위 호출 (가장 결정적 원인)**:
   - 코드베이스 전반에서 `--text-primary`(164회), `--border`(136회), `--bg-body`(68회), `--bg-surface`, `--bg-secondary` 등 18종의 CSS 변수가 빈번하게 호출되었으나, 정작 `src/index.css`에는 정의되어 있지 않았음.
   - 브라우저는 미정의 CSS 변수에 대해 기본값인 검은색(`#000000`)으로 폴백 렌더링하였고, 다크 모드(`--bg-card: #1f2937`) 진입 시 어두운 배경 위에 검은 글씨가 그려져 텍스트가 암흑 속에 파묻히는 참사가 전사적으로 속출함.
2. **인라인 하드코딩 색상 잔재**:
   - `Products.tsx`, `BillingInvoiceTab.tsx`, `SmartAsRequest.tsx`, `rent_assets.tsx`, `FieldAsManagement.tsx`, `InitialDbUploader.tsx` 등 15개 파일에서 `color: '#1e293b'`, `'#334155'`, `'#475569'`, `backgroundColor: '#ffffff'`, `'#f8fafc'` 등이 인라인으로 박혀 있어 테마 전환 시 대비가 파괴됨.
3. **배지(Badge) 색상 대비 미흡**:
   - 라이트 모드 및 다크 모드에서 배지 텍스트와 배경의 명도 대비가 낮아 WCAG 가독성 기준 미달.

---

## 3. 해결책 및 결과 (Resolution & Results)
1. **`src/index.css` 미정의 토큰 18종 전역 등록**:
   - `:root`와 `[data-theme='dark']`에 누락 토큰 18종을 상호 대칭으로 공식 선언하여 **미정의 CSS 변수 0건 달성**.
   - 다크 모드 검은 글씨 폴백 현상 완전 박멸.
2. **WCAG AAA급 고대비 뱃지 시스템 구축**:
   - `.badge-success`, `.badge-warning`, `.badge-danger`, `.badge-info`, `.badge-primary`, `.badge-secondary`의 배경색과 글자색을 라이트/다크 모드별로 명확히 분리하여 대비비 7:1 이상 확보.
3. **전체 메뉴 인라인 색상 시맨틱 토큰화**:
   - 15개 파일 대상 하드코딩 색상을 `var(--bg-card)`, `var(--text-main)`, `var(--text-muted)`, `var(--border-color)` 등의 시맨틱 변수로 일괄 안전 치환.
4. **빌드 검증**: `npx vite build` 0 에러 완결.

---

## 4. 체득 원칙 (Core Principles Learned)
- **시맨틱 CSS 변수 사전 완결 선언 원칙**: 컴포넌트에서 CSS 변수를 사용할 때는 반드시 `:root`와 `[data-theme='dark']` 양쪽에 해당 변수가 모두 선언되어 있는지 선제 검증한다.
- **원색 헥스 코드 인라인 하드코딩 영구 금지**: UI 요소 스타일링 시 `#ffffff`, `#000000`, `#334155` 등의 헥스 코드를 인라인에 직접 박지 않고, 항상 시맨틱 CSS 변수만을 사용한다.

# 렌탈 업계 일할 계산 공식 1,000원 단위 반올림 실증 규명 및 4단계 스마트 대사 엔진 정립

- **일자**: 2026-09-10
- **버전**: `v1.12.0.Build.41`
- **관련 파일**: `AppContext.tsx`, `rent_assets.tsx`, `~/.gemini/config/경험.md` (E-092)

---

## 1. 개요 및 배경
- 렌탈 자산(임차 장비 및 당사 임대 장비)의 월중 입출고·반납·대차 교체 시 일할 계산 금액 산정 기준에 대해, 100원 단위 반올림 vs 1,000원 단위 반올림 여부를 실제 유입된 16개 거래처 명세서(총 56건의 일할 계산 청구 데이터)를 전수 역추산하여 수학적·실증적으로 규명함.
- 사장님의 직관적 지적("일할 계산이 100원 단위가 아니고 1,000원 단위 처리가 아닌가?")을 바탕으로, 자사 시스템의 표준 일할 계산 공식과 외부 청구서 대사 엔진을 현실 데이터에 100% 부합하도록 개편함.

---

## 2. 실증 데이터 전수 검증 결과 (16개사 56건)
- **1,000원 단위(000원) 청구**: **54건 / 56건 (96.4%)** ➔ 압도적 업계 표준
- **100원 단위(00원) 청구**: **2건 / 56건 (3.6%)** ➔ 한솔렌탈 주식회사 1개사 특약

### 주요 거래처별 실제 청구액 역추산 검증
1. **하이로드((주)중부렌탈)**:
   - 월 640,000원 장비 2일 가동: `(640,000 / 30) × 2 = 42,666.66...원`
   - 100원 반올림 시: `42,700원`
   - **실제 청구액: `43,000원` (1,000원 단위 반올림)**
2. **주식회사 프린스렌탈**:
   - 월 200,000원 장비 8일 가동: `(200,000 / 30) × 8 = 53,333.33...원`
   - 100원 반올림 시: `53,300원`
   - **실제 청구액: `53,000원` (1,000원 단위 반올림)**
   - 20일 가동 건: `(200,000 / 30) × 20 = 133,333.33...원` ➔ **실제 청구액: `133,000원` (1,000원 단위 반올림)**
3. **주식회사 포스렌탈**:
   - 월 500,000원 장비 20일 가동: `(500,000 / 30) × 20 = 333,333.33...원`
   - 100원 반올림 시: `333,300원`
   - **실제 청구액: `333,000원` (1,000원 단위 반올림)**
4. **롯데렌탈(주)**:
   - 33건의 일할 및 특약 청구 전수 **1,000원 단위(000원)**로 청구 (317,000원, 63,000원, 295,000원, 383,000원 등)
5. **한솔렌탈 주식회사 (예외)**:
   - 월 200,000원 장비 28일 가동: `(200,000 / 30) × 28 = 186,666.66...원` ➔ **186,700원 청구 (100원 단위 반올림)**

## 3. 핵심 원칙 및 시스템 구현

### 3.1 자사 일할 계산 공식 전사 표준화 (`AppContext.tsx`)
- 고소작업대 렌탈 업계 표준인 **1,000원 단위 반올림**을 자사 표준 공식으로 확정:
  ```typescript
  const calcProRataAmount = (monthlyFee: number, dailyFee: number, days: number): number => {
    if (dailyFee > 0) {
      return Math.round((dailyFee * days) / 1000) * 1000;
    }
    return Math.round(((monthlyFee / 30) * days) / 1000) * 1000;
  };
  ```

### 3.2 4단계 스마트 대사 엔진 정립 (`rent_assets.tsx`)
외부 거래처 명세서 대사 시 자사 약정액과 원사 청구액을 비교할 때, 1,000원 표준뿐만 아니라 100원 단위 예외 업체까지 인지 마찰 없이 100% 자동 매칭하는 4단계 폴백 로직 적용:
1. **1순위 (전사 표준 1,000원 반올림 양편)**: `calcProratedFee(monthlyFee, days, 1000)` 일치 검증
2. **2순위 (전사 표준 1,000원 반올림 한편)**: `calcProratedFee(monthlyFee, daysOneWay, 1000)` 일치 검증
3. **3순위 (특약 호환 100원 반올림 양편)**: `calcProratedFee(monthlyFee, days, 100)` 일치 검증 (한솔 등)
4. **4순위 (특약 호환 100원 반올림 한편)**: `calcProratedFee(monthlyFee, daysOneWay, 100)` 일치 검증

## 4. 교훈 및 시사점
- 실무 도메인(특히 건설장비/고소작업대 렌탈)에서의 관행과 상거래 숫자는 단순한 프로그래밍 수학(정밀 나눗셈)과 다르며, 현장에서 통용되는 반올림 단위(1,000원 절사/반올림)가 실제 정산의 절대 표준으로 작용함.
- 직관에 의문을 품고 실제 56건의 명세서 데이터를 1:1 역추산하여 96.4%라는 명확한 근거를 확보함으로써, 시스템 공식의 신뢰도를 극대화하고 예외 거래처까지 유연하게 포용하는 시스템을 완성함.

# 🔬 [경험] Google Gemini Vision AI 기반 멀티모달 RPA 셀렉터 & 코드 자동 생성기 탑재

- **기록 일시**: 2026-08-21 17:35
- **프로젝트**: Universal RPA Recorder / UBUS Contract Editor (`v2.2.0.Build.15`)
- **원격 저장소**: [DragonRPA/RPA_Script_Editor](https://github.com/DragonRPA/RPA_Script_Editor)

## 💡 배경 및 문제의식

- 기존 웹/윈도우 RPA 개발에서 가장 큰 시간과 노력이 소모되는 병목 구간은 **복잡한 DOM 트리(AG-Grid, 난독화 클래스명, React/Vue 컴포넌트)에서 정확한 셀렉터(Locator)를 찾아내고 예외 처리를 구성하는 과정**이었음.
- 사용자가 F12 개발자 도구나 복잡한 인스펙터 분석 없이도, **"화면 스크린샷 1장 + 자연어 지시사항(예: 계약번호 검색 후 1행 더블클릭)"**만 입력하면 AI가 시각적 위치와 속성을 대조하여 최적의 파이썬 코드를 1초 만에 완성해 주는 멀티모달 비전 아키텍처를 도입함.

---

## 🛠️ 핵심 구현 및 아키텍처

1. **하이브리드 비전 듀얼 엔진 연동 (`ai_vision_agent.py`)**:
   - **Google Gemini (클라우드)**: `gemini-2.5-flash` / `gemini-2.5-pro` (0.8~1.5초 초고속, 초저비용 분석)
   - **Local Ollama (로컬 100% 무료/오프라인)**: `qwen3-vl:4b`, `gemma3:12b`, `llava` 등 사내망 완벽 보안 추론
2. **증거 기반(Evidence-Based) 실시간 DOM 수집기 (`dom_harvester.py`)**:
   - 대상 URL 접속 ➔ 실제 렌더링된 상호작용 가능 태그(`<input>`, `<button>`, `<table>`, `.ag-row` 등)의 실제 ID/Name/Class/라벨 힌트 실시간 정제 수집.
   - UI에 `[📄 실시간 DOM 증거 뷰어]` 패널을 제공하여 개발자가 눈으로 확인 가능.
3. **100% 무결점 Visual Grounding 파이프라인**:
   - `화면 이미지(눈)` + `실시간 HTML DOM(증거)` + `대상 URL(맥락)` + `자연어 지시(목표)` 4박자를 결합하여 추측/환각 없는 100% 실존 셀렉터 코드 완성.
4. **원클릭 GUI 캡처 모달 (`AIVisionModal`)**:
   - `[📋 클립보드 붙여넣기 (Ctrl+V)]`, `[📸 즉시 캡처]`, `[📁 파일 선택]`
   - `[🌐 실시간 DOM 수집 🔍]` 원클릭 버튼.
   - `[📋 에디터 커서에 코드 삽입]` 및 `[🤖 봇 에디터에 모듈로 즉시 추가]` 연동.

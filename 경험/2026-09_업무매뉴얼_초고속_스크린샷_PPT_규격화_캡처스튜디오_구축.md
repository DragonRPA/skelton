## 1. 구현 핵심 결과 및 문제 해결 요약

### 🎯 달성된 핵심 아키텍처
1. **`F9` 글로벌 캡처 오버레이**:
   - `ctypes.windll.user32.RegisterHotKey`를 활용하여 어떤 화면에서도 0.001초 만에 캡처 가동.
   - `win32gui.WindowFromPoint` 및 `GetWindowRect` 기반 **창 및 컨트롤 자석 자동 감지 스냅**.
   - 8방향 리사이즈 핸들, 방향키 1px 이동/조절, 실시간 돋보기 및 직전 영역 재사용(`R`).
2. **실시간 주석 및 텍스트 객체 자유 배치**:
   - 클릭 즉시 자동 카운트되는 번호 스탬프(`①, ②...`).
   - 텍스트 라벨 객체 생성 및 마우스 드래그 앤 드롭 자유 배치, 더블클릭 인라인 수정.
   - `Ctrl + Z` 실행 취소 시 번호 카운터 자동 롤백, 우클릭 삭제 시 뒤 번호 자동 재정렬(`reindex_stamps`).
3. **`F10` 슬라이드 내보내기 & 지속 세션 유지**:
   - `config.target_width` (기본 960px) 기준 Lanczos 초고화질 비율 유지 자동 리사이징.
   - PowerPoint COM(`win32com.client`)을 통해 열려 있는 활성 프레젠테이션의 새 슬라이드에 정중앙 자동 삽입 및 상단 단계 제목 상자 생성.
   - Windows 네이티브 `CF_DIB` 클립보드 주입으로 `Ctrl + V` 100% 호환.
   - 새 캡처(`F9`)를 시작하기 전까지 현재의 작업 이미지와 주석이 스튜디오 화면에 온전히 보존되어 수정 및 재전송 자유 보장.

## 2. 기술적 발견 및 해결 교훈 (Experience & Learnings)

### 1) Windows DIB(Device-Independent Bitmap) 클립보드 호환성
- 파워포인트나 워드에 클립보드 이미지를 붙여넣을 때 일반 PNG 바이너리나 파일 경로는 PPT 버전에 따라 텍스트나 알 수 없는 개체로 인식될 수 있음.
- PIL 이미지를 BMP 포맷으로 인메모리 저장 후, **앞의 14바이트 `BITMAPFILEHEADER`를 정확히 잘라낸 순수 DIB 바이너리**를 `win32clipboard.CF_DIB`로 전송해야 PPT에서 원본 선명도 그대로 즉시 붙여넣어짐을 확립.

### 2) 작업 세션 보존의 UX적 가치
- 일반 캡처 도구는 복사나 내보내기를 누르는 순간 창이 닫히거나 초기화되어, "아! 텍스트 한 글자 오타 났는데" 할 때 처음부터 다시 캡처해야 하는 마찰 계수가 매우 큼.
- 내보내기 후에도 현재 작업대 상태를 100% 유지하고, 오직 사용자가 명시적으로 `F9`를 눌러 새 캡처를 시작할 때만 세션이 교체되도록 설계함으로써 피로도를 획기적으로 낮춤.

### 3) 캡처 영역 지정 맥락의 자동 승계(Contextual Auto-Adoption) 및 핫키 채널 이원화
- **고정 영역 자동 승계**: 사용자가 화면에서 마우스로 영역을 한 번 드래그하여 캡처를 완료했다는 행위는 "이 화면 크기와 위치를 기준으로 연속 캡처하겠다"는 강력한 의사 표시임. 별도의 체크박스 클릭이나 저장 버튼을 강제하지 않고 완료 즉시 고정 영역으로 자동 등록 및 모드를 활성화해야 불필요한 번복 입력이 사라짐.
- **`F9` / `Shift + F9` 핫키 이원화**: 고정 영역이 설정된 후에는 `F9`를 누르면 오버레이 없이 0.01초 만에 즉시 캡처하고, 새 영역을 다시 잡고 싶을 때는 `Shift + F9`로 즉각 오버레이를 호출하는 이원화 체계를 구축하여 속도와 유연성을 동시에 확보함.
- **입력 채널 일관성**: 창 포커스 시의 `keyPressEvent`와 글로벌 백그라운드 핫키가 항상 동일한 비즈니스 라우팅 핸들러를 공유하도록 설계하여, 포커스 상태에 따른 오작동을 원천 방어함.

### 4) PyQt5 페인터의 엄격한 int 타입 요구와 paintEvent 예외 무조건 격리 원칙
- **QColor.setAlpha(int) 엄격성**: CSS/JSON 설정에서 `0.85`와 같은 float(0.0~1.0) 투과도 값이 들어왔을 때, PyQt5 C++ 바인딩은 파이썬의 float를 정수로 자동 변환해주지 않고 즉시 `TypeError`를 던짐. 설정값 유입부 및 렌더링 직전에 `int(opacity * 255)` 스케일링 및 `int()` 강제 캐스팅을 수행해야 함.
- **paintEvent 무조건 격리**: C++ Qt 렌더링 이벤트 루프 안에서 발생한 예외는 앱 전체를 비정상 급사시키므로, 루프 내 주석 객체 렌더링은 반드시 개별 `try...except` 방어막으로 감싸 무중단 복원력을 확보해야 함.

# [경험] 매뉴얼 스튜디오 PPT 슬라이드 단계명 제목 상자 커스텀 배치 및 서식 제어 엔진 구축

## 1. 배경 및 문제 의식
- 기존 스튜디오에서 F10을 눌러 파워포인트 슬라이드로 내보낼 때, 슬라이드 상단의 단계명 텍스트 상자(Step N. [단계명 입력])는 위치, 크기, 폰트가 코드로 고정되어 있었다.
- 현업에서 사용하는 실제 파워포인트 마스터 슬라이드 템플릿에는 상단 배너 영역, 회사 로고, 특정 컬러 바 등이 존재하여, 고정된 제목 상자가 배너와 겹치거나 배색이 어울리지 않는 사용성 저해 문제가 발생했다.
- 사용자가 원하는 위치(X, Y), 크기(너비, 높이), 글꼴 패밀리, 글꼴 크기, 굵기, 글자 색상, 그리고 문구 서식 템플릿을 자유롭게 지정하고 영구 보존할 수 있는 체계가 필요했다.

## 2. 해결 아키텍처 및 핵심 구현
- PowerPoint COM API 규격에 맞춘 TextFrame Margin 0화 및 Windows BGR 포맷(0x00BBGGRR) 색상 변환식 적용.
- 리본 메뉴 탭 2(서식·설정) 내 [PPT 제목상자] 전용 서식 그룹 신설 (제목 X, 제목 Y, 너비, 높이, 글꼴, 색상, 강조, 정렬).
- 환경 설정 다이얼로그(SettingsDialog)에 제목 상자 폰트명, 템플릿 문구 편집 기능 추가 및 QScrollArea 적용.
- config.json 및 .mcs.json 프로젝트 메타데이터에 100% 영구 보존 및 15개 단위 테스트 전수 PASS 검증.

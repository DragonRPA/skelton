## 1. 구축 성과 요약
- **Supabase Realtime Broadcast 기반의 초경량 무전기 네트워크 완성**:
  - 서버 경유 오디오 스토리지 저장 비용 없이 0.1초 만에 클라이언트 간 브로드캐스트로 음성 패킷(WebM/Opus Blob) 직결.
  - 전사 공용, 출고/배차, 현장 AS, 영업 4대 채널 및 특정인 대상 맞춤형 임시 채널 개설/삭제 완벽 지원.
- **클라이언트 단 0원 실시간 STT 텍스트 전사**:
  - Web Speech API(`webkitSpeechRecognition`)를 마이크 녹음과 동시 구동하여 별도의 유료 API 비용 없이 발언 즉시 텍스트화 및 채널 동시 전송.
- **수신자 3대 모드 (음성 / 비프음 / 완전 무음)**:
  - 사무실 근무자 및 회의 참석자도 업무 방해 없이 무전기를 상시 켜두고 텍스트/비프음으로 현장 상황을 조망할 수 있는 환경 완비.

## 2. 주요 기술적 난관 및 해결 (현장 UX 전환)
1. **Push-To-Talk (누르고 말하기) 제스처의 모바일 웹 한계**:
   - 데스크톱이나 물리적 무전기와 달리, 스마트폰 터치스크린에서 버튼을 길게 누르고 있는 행위(PointerDown 유지)는 브라우저 고유의 롱프레스 텍스트 선택/컨텍스트 메뉴를 유발하거나 작업 중 손가락이 미끄러져 의도치 않게 전송이 끊기는 문제가 발생함.
   - **해결책**: 원터치 토글 모드(`Tap-to-Talk`)로 전면 개편.
     - 1회 터치 ➔ 발언 시작 (녹음 개시, 붉은 맥동 애니메이션, 발언 초수 카운팅)
     - 2회 터치 ➔ 발언 종료 및 즉시 전송 (비프음 출력)
     - 작업자가 한 손으로 휴대폰을 쥐고 편안하게 말한 뒤 다시 터치하는 직관적이고 안정적인 조작성 확보.
2. **모바일 좁은 화면에서의 정보 밀도 및 가독성 확보**:
   - 오디오 플레이어 위젯이 화면의 절반을 차지하여 텍스트를 읽기 어렵던 문제를 해결.
   - 시간, 발신자, 콤팩트 재생기(`>`), 전문 텍스트 줄바꿈 구조로 고밀도 배치하여 한 화면에 5~8건의 최근 대화 내용을 즉시 파악할 수 있도록 최적화.
3. **당일 대화 보존 정책**:
   - 100건 제한을 제거하고 당일(자정까지)의 모든 대화를 무제한 보존하며, 날짜가 바뀌는 시점에만 자동으로 청소되는 로컬스토리지 기반 일일 생명주기 확립.

## 3. 재발 방지 및 시사점
- 물리적 장비의 UX(누르고 있기)를 모바일 터치 웹앱에 그대로 직역하면 모바일 브라우저의 이벤트 특성과 충돌함.
- "모바일 웹 터치 환경에서는 누르고 있기보다 터치-토글이 훨씬 안정적이고 피로도가 낮다"는 현장 인터랙션 표준을 정립함.

## 4. 모바일 한 손 그립 인체공학적 레이아웃 개편 (Thumb Zone 표준화)

- **일시**: 2026-09-04 15:08
- **문제 인식**:
  - 화면 중앙을 과도하게 점유하던 136px 거대 원형 버튼으로 인해 정작 중요한 '실시간 대화 피드'가 맨 아래로 밀려나는 정보 역류 발생.
  - 오른손으로 스마트폰을 쥐었을 때 화면 중앙 버튼을 터치하기 위해 손목과 엄지를 무리하게 꺾어야 하는 조작 피로도 상존.
- **해결 조치**:
  1. **상단 영역 초슬림 압축**: 헤더, 수신모드 1줄화, 채널 버튼 그리드, LCD 상태창을 컴팩트하게 슬림화하여 100px 이상의 유효 세로 공간 회수.
  2. **실시간 대화 피드 중앙 선행 배치**: LCD 바로 아래에 최근 6건의 대화 피드(과거 ➔ 최신 역순 정렬, 자동 스크롤)를 배치하여 화면에 들어오자마자 대화록을 즉각 조망.
  3. **최하단 인체공학적 가로 와이드 PTT 바 (52px, width 100%)**:
     - 오른손 엄지손가락이 자연스럽게 안착되는 화면 최하단에 가로 와이드 터치 바를 배치.
     - 발언 중 실시간 STT 버블을 버튼 바로 위에 띄워 말하면서 텍스트 전사 상태를 엄지손가락 위에서 한눈에 확인.
- **체득 원칙**:
  - 모바일 실무 UI에서 가장 중요한 완결 액션은 화면 중앙이 아닌 **최하단 엄지 영역(Thumb Zone)**에 가로 바 형태로 배치하고, 중앙 공간은 **상황 인지용 대화/데이터 피드**에 우선 양보한다.

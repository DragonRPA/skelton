## 1. 사장님의 핵심 질문과 도메인 원칙

> **"등록된 고객에 대하여, 기존정보가 없는데 생략하면 입력을 강력히 요구하고(다음 단계로 넘어가는것을 방어), 기존정보가 있을때 생략된 정보는 기존정보를 상속해주고, 기존정보가 있는데도 새로운 입력이 있다면 기존 정보에 대한 업데이트로써의 정보 추가로써 작동하는 로직을 적용"**

영업사원이 메신저에서 출고요청을 줄글로 올릴 때, 매번 긴 주소나 담당자 이메일을 다시 적는 것은 극심한 낭비이다. 반대로, 신규 현장이나 처음 거래하는 고객인데 주소나 연락처를 빠뜨리면 배차 기사와 자산 부서가 현장을 찾지 못해 대형 사고가 발생한다.

---

## 2. 3대 지능형 처리 로직

1. **🛡️ 1. 방어 가드 (Validation Guard)**:
   - 신규 고객이거나 기존 DB에 현장 상세 주소 / 현장담당자 연락처가 없는데 생략한 채 저장을 시도할 경우, **다음 단계 진행을 강력히 방어 및 차단**하여 깡통 데이터 생성을 원천 방지.
2. **⚡ 2. 지능형 자동 상속 (Auto-Inheritance)**:
   - 텍스트 파싱(`handleParse`) 및 고객/현장명 입력 시, 텍스트에서 생략된 정보(현장주소, 현장담당자, 청구담당자, 계산서 메일, 마감일, 결제일 등)를 기존 고객/현장 DB에서 **100% 자동 상속 대입**.
   - 화면에 `[⚡ 기존 DB 자동 상속됨]` 상태 배지 및 각 입력 필드별 상속 태그 표출.
3. **🔄 3. 최신화 동기화 업데이트 (Update & Augment)**:
   - 기존 고객/현장이 매핑된 상태에서 새로운 현장 주소, 새 담당자 연락처, 새 계산서 이메일이 입력되면, **고객 마스터(`customers`), 현장(`sites`), 담당자(`contacts`) 테이블을 최신값으로 즉시 동기화 UPDATE 및 신규 등록**.

## 3. 핵심 효익

- **영업사원의 노력 최소화 (10초 완결)**: 기존 고객의 경우 `고객명`, `현장명`, `모델명/수량`, `시간`만 적어도 나머지 주소/담당자/마감일이 100% 자동 채워짐.
- **배차/계약 데이터 무결성 100% 보장**: 주소나 연락처가 없는 불완전한 배차 지시가 시스템에 생성되는 것을 시스템 차원에서 원천 차단.
- **고객 마스터 DB 자동 최신화**: 별도의 거래처 관리 화면에 들어가지 않아도, 출고 요청 과정에서 고객의 최신 주소와 연락처가 자연스럽게 누적 갱신됨.

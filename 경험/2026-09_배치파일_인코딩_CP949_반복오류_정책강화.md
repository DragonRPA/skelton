# 경험 | 배치파일 인코딩 반복 오류 — CP949 강제 정책 고도화 (2026-09)

> **타임스탬프**: 2026-09-19
> **연결**: 글로벌 정책 AGENTS.md 카테고리 X 10.8

---

## 1. 반복된 증상

매번 배치파일(`.bat`)을 만들 때마다 한글이 깨지는 현상이 발생했다.
cmd.exe 화면에 '맹붕?맹붕?...' 형태로 출력되어 명령이 실행되지 않음.

## 2. 근본 원인

| 원인 | 설명 |
|------|------|
| `write_to_file` 도구의 기본 인코딩 | 도구 내부적으로 **UTF-8**로 파일 저장 |
| Windows cmd.exe의 기대 인코딩 | 한국어 환경에서 **CP949(ANSI)**만 해석 |
| 두 인코딩의 충돌 | 한글이 다른 바이트 시퀀스로 저장되어 깨짐 발생 |

## 3. 해결 방법 (영구 적용)

배치파일을 생성할 때 반드시 Python 스크립트를 경유하여 `encoding='cp949'`로 저장한다.

```python
# ✅ 올바른 방법
content = """@echo off
chcp 949 > nul
echo 한글 정상 출력
pause
"""
with open("파일명.bat", "w", encoding="cp949") as f:
    f.write(content)
```

## 4. 절대 금지 패턴

- ❌ `write_to_file`로 `.bat`/`.cmd` 직접 생성
- ❌ PowerShell `Set-Content`/`Out-File`로 배치파일 저장
- ❌ `open(f, 'w', encoding='utf-8')`로 배치파일 저장

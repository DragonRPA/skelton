# 경험: 이미지 분기 스텝 선택 시 이동 목적지 스텝 동적 행 강조 UI 구현

- **일시**: 2026-09-17 13:05
- **연결 발상**: [2026-08_UIA_기반_초고속_비전하이브리드_자동화.md](../발상/2026-08_UIA_기반_초고속_비전하이브리드_자동화.md)
- **연결 계획**: [2026-08_UIA_요소_저장소_및_목록_관리_구축.md](../계획/2026-08_UIA_요소_저장소_및_목록_관리_구축.md)
- **맥락**: 복잡한 조건 분기 매크로를 작성할 때 작업자가 이미지 분기 스텝(`STEP_IMAGE_BRANCH`)을 선택했을 때 조건 불일치 시 어느 스텝으로 점프하는지 한눈에 알기 어려운 문제를 해결하기 위해, 선택된 분기 스텝의 점프 목적지 스텝 행을 고유한 색상(Soft Gold/Amber)으로 동적 강조 표시하고, 아직 목적지 스텝이 작성되지 않은 미생성 상태에서는 분기 스텝 자체 행에 겹쳐서(Warm Peach/Coral) 명확히 안내하는 고밀도 시각적 UI 파이프라인을 구축함.

---

## 1. 달성 성과 (Key Achievements)

1. **이미지 분기 목적지 인덱스 정밀 산출 수식 확립**:
   - `STEP_IMAGE_BRANCH` 실행 시 미발견 시 `i += s.skip_count;` 후 루프 증감 `++i`가 실행되므로, 실제 점프 목적지 인덱스는 `target_idx = sel + s.skip_count + 1`임.
   - 0-based 리스트뷰 인덱스와 1-based 사용자 스텝 번호(`#`) 간의 상호 매핑을 완벽히 계산.

2. **조건부 동적 2원화 하이라이트 색상 파이프라인 구축**:
   - **케이스 1: 목적지 스텝이 존재하는 경우 (`target_idx < g_scenario.count`)**:
     - 목적지 행 배경: 부드러운 골드 옐로우 `RGB(254, 240, 138)` (Amber 200).
     - 목적지 행 텍스트: 깊은 앰버 브라운 `RGB(161, 98, 7)` (Amber 800) + 볼드 폰트(`g_ui.hFontBold`).
     - 행 테두리: 2px 외곽선 `RGB(217, 119, 6)` (Amber 600).
   - **케이스 2: 목적지 스텝이 아직 미생성된 경우 (`target_idx >= g_scenario.count`)**:
     - "표시할 스텝이 만들어지기 전에는 자신행을 겹쳐서 표시" 사용자 요구 완벽 반영.
     - 분기 스텝 자신 행(`sel`) 배경: 웜 피치/코랄 `RGB(255, 237, 213)` (Orange 100).
     - 텍스트: 딥 코랄 오렌지 `RGB(194, 65, 12)` (Orange 700) + 볼드 폰트.
     - 행 테두리: 2px 외곽선 `RGB(234, 88, 12)` (Orange 600).
     - 기본 윈도우 파란색 선택 배경 오버라이트를 위해 `CDIS_SELECTED` 플래그 제거 처리.
   - **케이스 3: 일반 스텝 선택 또는 선택 해제 시**:
     - 하이라이트 즉시 해제 및 기본 스타일 복원.

3. **Win32 ListView `NM_CUSTOMDRAW` 4단계 렌더링 파이프라인 완성**:
   - `CDDS_PREPAINT`: `CDRF_NOTIFYITEMDRAW` 통지 요구.
   - `CDDS_ITEMPREPAINT`: 목적지 행 검출 시 `CDRF_NOTIFYSUBITEMDRAW | CDRF_NOTIFYPOSTPAINT` 반환.
   - `CDDS_SUBITEM | CDDS_ITEMPREPAINT`: 모든 서브아이템(컬럼 0~4)에 대해 텍스트 배경색/전경색/폰트(`g_ui.hFontBold` 또는 비활성 시 `g_ui.hFontStrike`) 일괄 적용 후 `CDRF_NEWFONT` 반환.
   - `CDDS_ITEMPOSTPAINT`: `ListView_GetItemRect(..., LVIR_BOUNDS)` 영역을 기준으로 상/하/좌/우 2px 테두리 박스를 정밀 렌더링.

4. **실시간 선택 반응성 동기화 (`LVN_ITEMCHANGED`, `NM_CLICK`, `UI_UpdateList`)**:
   - 마우스 클릭, 키보드 방향키 이동, 스텝 이동/추가/삭제, 팝업 다이얼로그 수정 후 목록 갱신 시 `UI_UpdateBranchHighlight()`가 즉시 호출되어 목적지 행 강조가 0.01초의 딜레이 없이 실시간 반영됨.
   - 상태바에 `이미지 분기: 스텝 #%d ➔ 미발견 시 #%d 스텝으로 분기 이동 (스킵: %d스텝)` 또는 `... ➔ 이동 대상 스텝(#%d) 미생성 (자신행 중첩 표시, 스킵: %d스텝)` 명확히 안내.

## 2. 배운 점 및 핵심 경험 (Key Lessons Learned)

- **Win32 ListView의 CustomDraw 선택 상태 오버라이드 기법**:
  - `LVS_EX_FULLROWSELECT` 스타일이 적용된 ListView에서 특정 선택 행의 배경색을 커스텀하게 변경하려면, `CDDS_ITEMPREPAINT` 및 `CDDS_SUBITEM | CDDS_ITEMPREPAINT` 단계에서 `lplvcd->nmcd.uItemState &= ~CDIS_SELECTED;` 처리를 해주어야 윈도우 기본 셀렉션 브러시가 커스텀 배경색(`clrTextBk`)을 덮어쓰지 않음.
- **다단 컬럼(Report View)에서의 테두리 렌더링 최적 시점**:
  - 서브아이템마다 테두리를 그리면 중간 세로선이 겹쳐 지저분해지므로, `CDRF_NOTIFYPOSTPAINT`를 받아 전체 행 렌더링이 완료되는 `CDDS_ITEMPOSTPAINT` 시점에 `LVIR_BOUNDS` 사각형을 바탕으로 한 번에 행 전체 외곽선을 둘러주는 것이 가장 깔끔하고 전문적인 UI를 완성함.

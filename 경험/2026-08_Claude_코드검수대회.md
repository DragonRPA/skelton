## Claude가 최초 발굴한 것 (Gemini·GPT 전 대회 미발견)

### 1. visits.py 트랜잭션 원자성 훼손 (CRITICAL 2건)
- DB 커밋 **이후**에 카카오 API 호출 → 알림 실패 시 롤백 불가
- 출장 접수(221라인)와 완료(412라인) 양쪽에 동일 패턴 존재
- **심층 추론(Thinking)으로 실행 흐름의 타이밍 문제를 잡아냄**

### 2. JWT가 사실상 가짜 구현
- 접두사(`dev-`, `space-`) 또는 길이만 체크 → 서명·만료 미검증
- `REQUIRE_AUTH` 기본값 `false` → 미설정 시 전체 인증 해제

### 3. ConsultLog customer_id FK 완전 누락 (DB 설계 결함)
- customer_name 문자열만 저장, 실제 Customer 테이블과 연결 없음
- 조인·통계·이력 추적 전면 불가

### 4. ORM relationship 전면 미선언
- 프로젝트 전체에 `relationship()` 단 한 줄도 없음
- 전 엔드포인트가 raw SQL 텍스트 쿼리 의존 → N+1 해소 불가 구조

## 재발 방지 원칙

1. **외부 API 호출은 항상 DB 커밋 전 또는 이벤트 큐로 위임**
2. **인증 기본값은 가장 제한적인 방향(true)으로 설정**
3. **ORM 모델 설계 시 relationship() 선언을 최우선 체크리스트에 포함**
4. **Pydantic 스키마에 Literal/Enum + max_length를 필수로 적용**
5. **requirements.txt는 항상 `==` 버전 고정**

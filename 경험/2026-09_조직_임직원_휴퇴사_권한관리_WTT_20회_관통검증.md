## 🔍 2. 적발된 결함 및 정밀 개편 내역

### 2.1 브라우저 alert 7건 및 confirm 2건 전면 퇴출 (헌장 5.2)
- 부서 삭제 시 브라우저 `confirm`을 전면 퇴출하고 전용 커스텀 모달(`deptToDelete`) 구축.
- 프로필 저장, 부서 저장 시 `alert`를 전면 퇴출하고 세련된 자체 `showToast` 컴포넌트로 대체.
- 최고관리자 상태변경 차단, 부서 삭제 불가 경고 시 `showErrorModal` 적용.

### 2.2 부서 삭제 및 임직원 라이프사이클 5대 방어 가드 강화
1. **구성원 잔존 부서 삭제 차단**: 소속 직원이 1명이라도 존재하면 부서 삭제 불가 가드 발동.
2. **하위 부서 잔존 상위 부서 삭제 차단**: 하위 부서가 존재하는 상위 부서는 삭제 불가 가드 발동.
3. **최고관리자 불변성 가드 (Immutability)**: 최고관리자(`admin`, `sys-admin`, `u-1`) 계정의 휴직/퇴사/권한박탈 시도 원천 차단.
4. **퇴사자 로그인 차단 가드**: `status === 'RETIRED'`인 퇴사자의 시스템 로그인 시도 원천 차단.
5. **특권 메뉴(permission) 일반 직원 부여 차단 가드**: 사용자 권한 설정 메뉴는 오직 `ADMIN` 등급에게만 부여 허용.

### 2.3 Gutenberg Z-패턴 4단계 조직/인사 대차대조 검증 바 탑재 (헌장 3.5)
- $\text{총 임직원: } N\text{명} = \text{재직: } N\text{명} + \text{휴직: } N\text{명} + \text{퇴사: } N\text{명} \mid \text{부서: } N\text{개 (배정: } N\text{명, 미배정: } N\text{명)} \mid \text{대차 차액: } 0\text{명 (정합)}$

## 💡 4. 배운 점 및 교훈 (Experience)
1. **조직도와 임직원 마스터는 시스템 보안의 근간**:
   부서 삭제 시 고아(Orphan) 직원 발생을 방지하고, 퇴사 처리 시 권한 및 로그인을 즉각 무효화하는 라이프사이클 관리가 전사 보안의 핵심임을 확인하였다.
2. **참조키(FK) 무결성과 고스트 권한 정돈**:
   임직원 삭제나 퇴사 시 과거 권한 레코드가 고스트로 남아 시스템 장애를 일으키는 문제를 1-Click 자동 진단/정돈 메커니즘으로 원천 방어하였다.

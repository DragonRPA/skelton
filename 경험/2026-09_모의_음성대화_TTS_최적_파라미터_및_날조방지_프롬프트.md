# 2026-09 모의 음성대화 시나리오 TTS 최적 파라미터 및 날조 방지 프롬프트 정립

- **기록일자**: 2026-09-07
- **도메인/프로젝트**: 기연리프트 TTS / 모의 음성대화 시나리오 일괄 생성 시스템

---

## 1. 배경 및 당면 과제
- 렌탈/출고/물류 현장의 문자 데이터(장비명, 일시, 현장명, 수신자 등)를 기반으로 2인 간의 실감 나는 전화 통화 음성을 일괄 합성하는 파이프라인 구축.
- 초기 실행 시 발생한 3대 난관:
  1. **LLM의 환각/날조(Hallucination)**: 존재하지 않는 가상 모델명, 임의의 인물, 허구의 옵션을 지어내 실무 데이터로서의 가치가 훼손됨.
  2. **발화 템포와 톤의 부자연스러움**: 기본 TTS 음성 속도가 지나치게 느리고 대화 간 쉼표 간격이 어색함.
  3. **TTS 엔진의 처리 속도 병목**: Qwen3-TTS 대비 대량 단락 일괄 처리에 적합한 초고속 파이프라인 요구.

---

## 2. 발견 및 해결책 (최적 파라미터 조합)

### ① LLM 최적 조합: `gemma3:4b` + `Temperature: 0.25`
- `Temperature 0.7`: 창작 소설 수준으로 환각 발생.
- `Temperature 0.0~0.1`: 너무 기계적이고 통화 맞장구가 경직됨.
- **`Temperature 0.25`**: 팩트 앵커링(요약 정보에 기재된 장비명, 대수, 일시만 엄격 질문)을 철저히 유지하면서도 실제 전화 통화의 자연스러운 맞장구("아, 네!", "확인 감사합니다", "맞습니다")가 살아나는 최적의 균형점.

### ② TTS 최적 조합: `MeloTTS (Korean)` + `Speed: 1.1x` + `Pause: 0.3초` + `전화통화 필터(300~3400Hz)`
- 문장당 약 1초 내외로 초고속 합성 가능.
- 속도 `1.1x`와 간격 `0.3초`로 실제 비즈니스 전화 통화의 빠른 호흡을 완벽히 재현.
- 300Hz~3400Hz 대역통과 필터로 수화기 음향 완성.

### ③ 프롬프트 3대 날조 방지 규칙 정립
```text
- "모델명 * n" 형식의 텍스트는 "모델명 n대" 로 출력하세요.
- [요약 정보]에 명시되지 않은 장비 모델명, 옵션, 일정, 인물, 금액 등을 절대로 임의로 지어내지 마세요.
- 오직 주어진 [요약 정보]에 적혀 있는 내용만을 묻고 답하며 확인(크로스체크)하는 대화로만 구성하세요.
- 정보가 없는 항목은 상상해서 말하지 말고, "추후 확인 후 연락드리겠다" 정도로만 언급하세요.
```

## 3. 효익 및 교훈
- 소형 로컬 LLM(`gemma3:4b`)이라도 프롬프트 제약과 낮은 Temperature(0.25)의 결합을 통해 대형 모델 못지않은 엄격한 팩트 준수 대화를 100% 로컬 환경에서 안정적으로 대량 생산할 수 있음을 검증함.

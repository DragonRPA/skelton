## 1. 달성 성과 (Key Achievements)

1. **UIA 전용 코어 엔진 (`engine_uia.h`, `engine_uia.c`) 신설**:
   - `IUIAutomation` COM 인터페이스 바인딩 (C 언어 `COBJMACROS` / `CINTERFACE` 완벽 호환).
   - 5대 UIA 액션 함수 탑재:
     - `UIA_ClickElement`: Invoke/Toggle/Selection/BoundingRect 클릭
     - `UIA_SetElementText`: ValuePattern을 통한 유니코드 텍스트 직접 주입 (IME 한영 전환 문제 100% 원천 차단)
     - `UIA_ToggleElement`: TogglePattern을 통한 약관/옵션 체크박스 강제 ON/OFF
     - `UIA_SelectComboItem`: SelectionItemPattern을 통한 콤보박스 즉시 선택
     - `UIA_WaitElementState`: `CurrentIsEnabled` 상태 비동기 대기
     - `UIA_AutoPassWizard`: 설치 마법사 약관 체크 + 다음/설치 연쇄 통과
     - `UIA_GetElementFromPoint`: 마우스 커서 위치 요소 실시간 스니핑 및 초록색 박스 하이라이트

2. **메인 UI 레이아웃 UIA 전용 영역 독립 배치**:
   - 우측 패널에 **[Row 3: UIA 전용 도구 그룹 바]**를 신설하여 일반/비전 스텝과 명확히 분리:
     `[🔍 UIA 스파이] [UIA 클릭] [UIA 텍스트입력] [UIA 체크설정] [UIA 콤보선택] [UIA 상태대기] [UIA 마법사통과]`
   - `UI_ShowUiaStepDialog`: UIA 6종 스텝 추가/수정용 통합 대화상자 구현 (실시간 테스트 및 하이라이트 연동).
   - `UI_ShowUiaSpyDialog`: F2 원클릭 스텝 등록 및 실시간 요소 스니핑 도구 구현.

3. **시나리오 직렬화 및 재생기 연동**:
   - `MacroStep` 6종 UIA 스텝 열거형 및 필드(`win_title`, `uia_name`, `uia_id`, `uia_type`, `uia_val`, `uia_state`) JSON 입출력 완비.
   - `PlaybackThreadProc` 및 `UI_EditStep` 전수 연동 완료.

## 2. 배운 점 및 핵심 경험 (Key Lessons Learned)

- **C 언어에서 COM API 사용 시 `COBJMACROS` 선언 필수**:
  - C++이 아닌 순수 C 컴파일러(`cl.exe`) 환경에서는 `COBJMACROS`와 `CINTERFACE`를 `#include <windows.h>` 이전에 선언해야 `IUIAutomation_ElementFromPoint` 등의 매크로가 정상 생성됨.
- **문자열 포맷팅 내 따옴표 충돌 방지**:
  - `swprintf_s` 포맷 스트링 내에 이스케이프가 누락될 위험이 있는 경우, `L"요소 이름: [%s]"`와 같이 대괄호 문법을 사용하는 것이 파싱과 유지보수 측면에서 훨씬 안전함.

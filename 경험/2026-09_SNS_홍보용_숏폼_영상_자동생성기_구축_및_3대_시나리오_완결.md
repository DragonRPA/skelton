# 2026-09 SNS 홍보용 숏폼 영상 자동 생성기 구축 및 3대 시나리오 렌더링 완결

## 1. 개요 및 배경
- **목적**: YouTube Shorts, Instagram Reels, TikTok, Facebook 등 SNS 채널을 통한 Dragon RPA 제품군 및 **매뉴얼 스튜디오(Manual Studio)** 판촉을 위한 무인 완전 자동 숏폼 영상 제작 파이프라인 구축.
- **핵심 요구사항**:
  - Python 기반 9:16 세로형(1080x1920) 30FPS 초고속 자동 렌더링.
  - 고품질 한국어 신경망 성우(Microsoft Edge-TTS)와 FFmpeg 실시간 스트리밍 인코딩 파이프라인 결합.
  - 제안된 3대 킬러 시나리오([칼퇴 공감 편], [비포 & 애프터 편], [개인정보 & 보안 편]) 기본 탑재 및 완성본 `.mp4` 자동 렌더링.

---

## 2. 주요 아키텍처 및 구현 내역

### A. 음성 및 타임라인 동기화 엔진 (`engine/tts_generator.py`)
- `edge_tts.Communicate(text, voice, rate)`를 활용하여 0초 만에 고품질 신경망 음성 생성.
- 생성된 음성을 16-bit 44.1kHz WAV로 변환하여 씬별 시작 시간, 재생 시간, 버퍼 묵음(0.3s)을 프레임 단위로 정밀 동기화.
- 전체 씬을 단일 마스터 음성 트랙(`master_narration.wav`)으로 자동 병합.

### B. 시각 디자인 및 모션 렌더러 (`engine/visual_renderer.py`)
- **해상도**: 1080x1920 (9:16 모바일 최적화 세로형)
- **상단 브랜딩**: `DRAGON RPA | 매뉴얼 스튜디오` 브랜드 캡슐 & 상황별 뱃지
- **중단 무대 (Hero Stage)**:
  - `problem` 모드: 다크 레드 경고 컨테이너 + 기존 수동 방식(야근 3시간) vs 매뉴얼 스튜디오(1분 완성) 대조표.
  - `ui_demo` 모드: macOS 스타일 윈도우 프레임 안에서 UI 캡처 스크린샷 줌인/팬 모션(Ken Burns 효과) + 자동 번호 태그 뱃지.
  - `cta` 모드: 제품 소개 카드 + 펄스 CTA 버튼 + 공식 랜딩 도메인 안내.
- **하단 자막**: 가독성이 극대화된 맑은 고딕 볼드 폰트 + 핵심 키워드 옐로우/시안 자동 하이라이트.
- **최하단**: 영상 진행률 프로그레스 바.

### C. 비디오 합성 파이프라인 (`engine/video_composer.py`)
- Pillow로 생성된 raw RGB24 바이트 스트림을 FFmpeg `stdin` 파이프로 직접 스트리밍.
- 대용량 디스크 I/O 없이 메모리 상에서 직접 H.264/AAC MP4로 인코딩하여 **28초 분량 영상을 약 20초 만에 초고속 렌더링**.

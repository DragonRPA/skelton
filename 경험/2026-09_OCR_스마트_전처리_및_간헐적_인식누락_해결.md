# OCR 스마트 전처리 파이프라인 및 간헐적 인식 누락 해결 (2026-09)

## 1. 배경
매뉴얼 스튜디오의 텍스트 인식(OCR 추출 O, OCR 라벨 Shift+O) 기능에서, 대화상자나 긴 문장을 넉넉하게 잡을 때는 인식이 잘 되지만, '저장', '확인', '로그인', '환경설정' 등 버튼 하나나 단어 하나를 타이트하게 드래그하면 전혀 인식이 되지 않거나 아무런 피드백 없이 침묵하는 문제가 발생함.

## 2. 근본 원인 분석
1. **외곽 여백(Margin) 부재로 인한 문자 분할(Segmentation) 실패**:
   - Windows 내장 WinRT OCR 엔진(Windows.Media.Ocr.OcrEngine)은 잘라낸 이미지의 외곽 테두리(0~1px)에 글자 획이 맞닿아 있으면, 이를 윈도우 창 테두리나 UI 구분선 노이즈로 간주하여 텍스트 분할 단계에서 버림.
2. **화면 폰트의 저해상도 & 획 두께 한계**:
   - 11~13pt 화면 폰트는 높이가 15~25px, 획 두께가 1~2px에 불과함. WinRT OCR은 40~50px 미만의 저해상도 영역에서 신경망 문자 검출 필터를 통과시키지 못함.
3. **무음 실패(Silent Failure)로 인한 사용성 착시**:
   - 텍스트가 미인식되어 빈 문자열('')이 반환될 때 아무 피드백 없이 조용히 종료되어 프로그램이 먹통인 것으로 오인됨.

## 3. 해결책 및 체득 원칙
1. **스마트 전처리 파이프라인(Smart Preprocessing)**:
   - 모서리 4점 배경색 자동 샘플링 기반 외곽 16px 패딩 여백 추가 (테두리 노이즈 필터링 방지).
   - 높이/너비 기반 적응형 Lanczos 2.0x~3.0x 고품질 업스케일링 및 선명도(Sharpness 1.2x) 강화.
   - 1차 전처리(2x) -> 2차 고배율 전처리(3x) -> 3차 원본 다단계 폴백 체인 구축.
2. **무음 실패 차단(Zero Silent Failures)**:
   - 미인식 시 toast_ocr_no_text ('텍스트 미인식 (더 넓게 드래그)') 토스트 즉시 표출.
3. **드래그 임계값 완화**:
   - width >= 10 and height >= 8 로 낮추어 초소형 버튼도 정상 인식 트리거.

## 4. 실증 결과
- 표준 폰트(맑은 고딕 12pt) 기준 원본 크롭 시 5개 단어 전수 0% 인식 실패 -> 스마트 전처리 통과 시 5개 단어 전수 100% 인식 성공 ('저장', '확인', '로그인', '환경설정', '매뉴얼 스튜디오').
- ManualStudio v1.4.0.Build.23 릴리즈 및 단위 테스트 56개 전수 통과 (100% ALL PASS).

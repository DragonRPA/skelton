## 1. 배경 및 문제 의식
- 기존 ERP는 PC 환경에 맞춰 15~30행 고밀도 테이블 그리드와 마스터-디테일 2단 분할 레이아웃으로 설계됨.
- 스마트폰 브라우저로 접속 시 15개 이상의 사이드바 메뉴가 화면의 2/3을 가리고 터치 타겟이 협소하여 현장 기사 및 담당자의 실무 조작이 극히 비효율적임.
- 전체 ERP를 반응형으로 뜯어고치는 것은 기술 부채를 유발하므로, **모바일이 실제로 필요한 20% 핵심 기동 직무(현장 AS, 배차 확인, 출고 검수, 간이 가용자산 조회)만을 추출하여 모바일 전용 PWA(`/m`)로 분리 구축**하기로 결정함.

---

## 2. 멀티에이전트 4대 관점별 핵심 전략
1. **PM 관점**: 4단계 단계별 롤아웃 (Phase 1: 현장 AS ➔ Phase 2: 배차 기사용 운송 ➔ Phase 3: 출고 검수 ➔ Phase 4: 영업 가용자산 조회)
2. **UI/UX 관점**: 
   - 2대 필드 테마: `Field High-Contrast Dark` (야외 시인성 극대화) & `Field Clean Light`
   - 56px+ 대형 터치 타겟, 횡스크롤 0%의 단일 수직 카드 피드(Card Dossier), 하단 엄지손가락 내비게이션 바
   - 전사 표준 3.1 무수식어 건조한 명사·동사 문법 강제
3. **시스템 엔지니어 관점**:
   - 동일 Supabase DB 및 `AppContext`, `db.ts` 비즈니스 로직 100% 재사용
   - URL `/m` 라우트 및 모바일 뷰포트 자동 감지 분기
   - PWA Standalone 모드 지원 및 카메라/서명패드/TMAP 딥링크 네이티브 브라우저 API 연동
4. **실무 담당 부서 관점**:
   - 정비: 탑차 부품 실시간 차감, 현장 사진 4장 촬영, 원터치 길안내, 고객 서명
   - 배차: 상하차지 원터치 전화연결, 상하차 완료 1-Click 보고
   - 출고: 10대 법정/기능 검수 체크리스트 원터치 패스, 승인 시 자산 상태 `RENTED` 자동 전환

## 3. 기대 효과
- 현장 임직원의 조작 클릭 수 70% 이상 감소 및 입력 오류 원천 차단
- 모바일-PC 간 데이터 단절 없는 100% 실시간 동기화
- 전사 표준 헌장 제1조(임직원 최소 노력 대비 최대 효익·편익 창출) 완벽 구현

## 1. 세부 실행 계획 (Action Plan)

1. **설정 구조체 확장 (`include/app_config.h`, `src/app_config.c`)**:
   - `AppConfig`에 `bool use_uia` 필드 추가.
   - `config.json` 직렬화/역직렬화 (`LOAD_BOOL`, `cJSON_AddBoolToObject`) 구현.
   - 배포 전 `config.json`을 통해 `use_uia = false` 사전 설정 가능.

2. **코어 엔진 가드 (`src/engine_uia.c`)**:
   - `UIA_Init()` 진입 시 `if (!g_app.use_uia) return false;` 사전 차단 가드 적용.
   - `use_uia = false`일 때 COM API(`CoCreateInstance`, `UIAutomationCore.dll`) 단 1라인도 미호출.

3. **UI 환경설정 패널 및 툴바 상태 연동 (`include/ui_main.h`, `src/ui_main.c`)**:
   - 좌측 패널 환경설정 영역에 `[v] UIA 모듈 사용` 체크박스(`IDC_CHK_USE_UIA`) 배치.
   - `UI_UpdateUiaControlState()` 구현: `use_uia` 상태에 따라 우측 Row 3 UIA 버튼 7종 자동 활성화/비활성화.
   - `IDC_CHK_USE_UIA` 토글 시 `AppConfig_Save()` 즉시 호출 및 미사용 시 `UIA_Shutdown()`으로 메모리/COM 해제.
   - `PlaybackThreadProc`: UIA 스텝 실행 시 `use_uia` 비활성 상태면 안전하게 알림 후 스킵.

4. **빌드 검증 및 릴리즈**:
   - `build.bat` 컴파일 (0 경고, 0 에러 검증).

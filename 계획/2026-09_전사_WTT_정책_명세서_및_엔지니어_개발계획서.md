## 1. 계획 수립 배경

사장님의 명시적 지시에 따라, 새로운 문제점을 발굴하지 않고 오늘 식별된 모든 정책, 아이디어, 개발요구사항이 완벽히 적용되었는지를 전수 검증하기 위해 PM, 엔지니어, 영업, 정비, AS, 배차, 관리, 진상고객, 감사팀 전원이 참여하는 WTT 워크숍을 성공적으로 완료함.
PM과 감사팀의 합동 중간보고서(전사 실무 임직원 평균 94.6점)를 바탕으로, 엔지니어링 본부의 3단계 후속 개발 계획을 확립함.

---

## 2. 3단계 후속 개발 실행 계획

### Phase 1: CI 회귀 테스트 자동화 및 안정성 강화 (즉시)
1. `package.json` 내 `npm test` 스크립트에 `wtt_full_business_activity_suite.cjs` 연동 (GitHub Actions push 시 자동 검증).
2. Supabase PostgREST 캐시 전파 지연 대응 1초 3회 지수 백오프 인터셉터 구현.

### Phase 2: 실무진 피드백 기반 미세 편의 UX 고도화 (단기)
1. AS팀/영업팀: `SmartAsRequest.tsx` 접수 완료 후 3초 카운트다운 Undo(실행취소) 플로팅 바 제공.
2. 배차담당: 단일 `EXCHANGE` 배차의 시차 출고 발생 시 원클릭 2건 연계 분할 생성 마법사.
3. 정비팀: 정비 대장 상단 공장 오버홀 vs 출장 AS 퀵 토글 칩 뷰 지원.

### Phase 3: 외부 연동 자동화 및 DB 물리적 락 (중장기)
1. 관리팀: 법인카드 승인내역 및 우체국 e-그린우편 API 연동 사전 아키텍처 수립.
2. 감사팀: 마감 결산 레코드(`payroll_closings`, `depreciation_logs`) DB Row-Level Locking 트리거 장착.

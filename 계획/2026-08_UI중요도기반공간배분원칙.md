## 원칙의 완성

### 1단계 발상 (UI 중요도 Scoring)
> "중요하지 않은 것의 비중을 줄여야 한다"

### 2단계 계획 (채움의 원칙)
> **"줄인 공간에는 반드시 더 높은 가치를 채워야 한다. 빈 공간, 큰 글자, 큰 버튼은 채움이 아니다."**

설계 변경의 성립 조건:
1. 축소 대상 식별 (Score 낮은 요소)
2. 축소한 만큼의 공간에 채울 가치 식별 (Score 높은 정보)
3. 두 조건이 동시에 성립할 때만 변경 승인

## ConsultParser2 적용 계획

### 축소 대상
- 1단계 버튼 (스키마 정규화) — Score 2, 현재 풀폭 점유

### 채움 대상 — "분석 준비 상태 패널"

1단계 버튼을 축소한 공간에 들어갈 실질 정보:

```
┌─────────────────────────────────────────────────────┐
│ 📚 군집화 사전 상태                                    │
│  등록 어구: 1,500개 / 전체: 13,135개 (커버율: 11.4%)   │
│  마지막 갱신: 2026-08-16 21:57                        │
│  → 판단: "사전 갱신 후 전체 재실행 권장"                │
├─────────────────────────────────────────────────────┤
│ 📊 직전 분석 스냅샷                                    │
│  실행일시: 2026-08-16 22:10 | 분석 건수: 32,693건      │
│  고장 판정률: 47.2% | 최다 계통: 흡입계통               │
│  → 판단: "집계만 재실행으로 결과 갱신 가능"              │
└─────────────────────────────────────────────────────┘
```

### 이 패널이 주는 가치
- 사용자가 매번 "1단계 실행 → 2단계 실행"을 맹목적으로 누르지 않아도 됨
- "사전이 최신인가?", "집계만 재실행하면 충분한가?"를 UI에서 즉시 판단 가능
- Score: 8 — 의사결정 지원 정보, 핵심 실행 액션과 동급

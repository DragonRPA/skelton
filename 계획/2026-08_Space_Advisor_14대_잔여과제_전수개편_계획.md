## 1. 개요 및 목적
1~4차전에 걸쳐 발굴된 86건 중 기완료된 72건 외에 남아있는 14대 잔여 과제(보안/인증, 완전 오프라인 PWA, 데스크탑 중앙 모달화, 키보드 네비게이션, Alembic 스키마 정합성, Aligo 실운영 연동 등)를 전수 해결하여 시스템의 완성도와 비즈니스 효익을 극대화한다.

---

## 2. 5대 핵심 실행 단계

### [단계 1] 보안 및 인증 / 인가 하드닝 (과제 1, 2, 3)
- API 토큰 인증 미들웨어 및 Rate Limiting 방어 로직 적용
- CORS 프로덕션 화이트리스트 정돈

### [단계 2] DB 스키마 & Alembic 정합성 & 원천 데이터 (과제 4, 5, 6)
- Alembic 신규 리비전에 `pg_trgm` GIN 인덱스 및 제약조건 정식 편입
- `VehicleInventory` (차량별 재고) 모델링 및 원천 데이터 파이프라인 보강

### [단계 3] 모바일 PWA 오프라인 & 사진 & 기사 동기화 (과제 7, 8, 9)
- `GET /api/v1/employees` 실시간 연동 드롭다운 구축
- 현장 정비 사진 첨부/촬영 UI 구현
- Service Worker (`sw.js`) 캐싱 등록

### [단계 4] 데스크탑 상담원 UI/UX & 동선 혁신 (과제 10, 11, 12, 14)
- 출장 접수 창을 우측 드로어에서 **중앙 집중식 모달(Modal)**로 전환 (패널 C 시각적 차폐 완벽 해결)
- 고객 검색 인풋 키보드 화살표(`↑`/`↓`) 및 `Enter` 키보드 네비게이션 지원
- LLM 엔진 상태 가시성 및 AudioContext 정리 최적화

### [단계 5] 알림톡 상용 API 연동 및 통합 실측 검증 (과제 13)
- Aligo 카카오 알림톡 HTTP API 페이로드 연동
- 14대 과제 실측 통합 검증 스위트 실행 (`run_backlog_verification.py`)

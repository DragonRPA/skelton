## 1. 개요 및 목적
- 고소작업대 렌탈 현장(주기장 상차, 출고 검수, 배차 기사, 현장 AS 출동)에서 전화 통화의 한계를 극복하고, 스마트폰 PWA 기반의 다자간 실시간 무전(Push-To-Talk) 음성 통신망을 구축함.
- 사용할 임직원만 필요 시 `[무전 ON]`으로 켜두고, 화면 중앙의 PTT 버튼을 누르고 말하면 동료들에게 실시간 음성 방송이 자동 송출되도록 구현.

---

## 2. 세부 개발 단계 (Implementation Phases)

### 1단계: 무전기 오디오 엔진 및 Supabase Realtime 브로드캐스트 서비스 구축
- 파일: `src/services/walkieTalkieService.ts`
- 기능:
  - Web Audio API 기반 오디오 녹음 (`MediaRecorder`, Opus/WebM 압축, 16kHz 모노 초경량 데이터).
  - 음향 효과음 엔진 (무전기 시작 비프음, 종료 치-익 노이즈, 오류음 Web Audio 오실레이터 합성).
  - Supabase Realtime Broadcast 채널(`walkie_talkie_channel_${channelId}`) 구독 및 음성 이벤트 실시간 수신/자동 재생.
  - 전송 실패 대비 R2 또는 Supabase DB 백업 및 최근 20건 로컬 캐싱.

### 2단계: 모바일 무전기 전용 UI 컴포넌트 개발
- 파일: `src/mobile/components/MobileWalkieTalkieModal.tsx` & `MobileWalkieTalkieWidget.tsx`
- 구성:
  - 상단 헤더 무전기 On/Off 토글 뱃지 (실시간 On 임직원 수 표출).
  - 무전기 팝업 스튜디오:
    - 4대 채널 선택 탭: `전사 공용`, `출고/배차`, `현장 AS`, `영업`.
    - 현재 채널 접속 중인 동료 목록 인라인 표시.
    - 화면 중앙 대형 원형 PTT 버튼 (`[누르고 말하기]`, 터치/마우스 이벤트 완벽 대응).
    - 송신 중 시각적 파형 및 붉은색 점멸 피드백.
    - 수신 시 발신자 프로필(부서, 이름, 시각) 및 자동 스피커 방송.
    - 최근 무전 타임라인 (다시듣기 버튼 탑재).

### 3단계: 모바일 헤더 및 전사 모바일 앱 연동
- 파일: `src/mobile/MobileHeader.tsx`, `src/mobile/MobileApp.tsx`
- 기능:
  - 헤더 우측에 `[📻 무전기 ON/OFF]` 퀵 버튼 배치.
  - 백그라운드 리스닝 모드 유지 (`isWalkieTalkieOn: true` 시 어느 화면에서든 수신 음성 자동 재생).

### 4단계: 컴파일 검증 및 배포
- `npm run build` 검증.
- `RELEASE_NOTES.md` 및 `dev_temp.md` 작성.
- git 커밋 및 푸시.

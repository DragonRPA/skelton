## 1. 계획 개요 (Overview)
- **배경**: 화물 기사 배정 완료 후, 배차 담당자가 상차지/하차지/연락처/운송료/유의사항을 기사에게 전달하기 위해 별도로 수기 문자나 카카오톡을 작성하는 번거로움 해소.
- **해결 방안**:
  - 유료 문자 발송 API 대신, 스마트폰 브라우저 표준인 `sms:` 딥링크 프로토콜을 활용하여 비용 0원의 1초 원클릭 발송 체계 구축.
  - 배차 정보(배차번호, 차량번호, 기사명, 상차지, 하차지/현장명, 현장인수자 연락처, 확정운송비, 적재장비 제원)를 정형화된 배차안내 텍스트로 자동 조립.
  - 딥링크 실행 즉시 스마트폰의 기본 문자 앱(삼성 메시지 등)이 열리며, 수신자 번호와 전문이 100% 자동 채워진 상태로 대기.
  - PC 환경에서는 1클릭 클립보드 복사 및 카카오톡/PC 문자 붙여넣기 연동 지원.

## 2. 단계별 실행 계획 (Implementation Steps)

### 1단계: 배차 안내 문자 생성 및 딥링크 유틸리티 구축 (`src/utils/nativeLauncher.ts`)
- `buildDispatchSmsText(delivery, options)`: 출고(`OUTBOUND`), 회수(`RETURN`), 교환(`EXCHANGE`, 헌장 2.3) 유형별 맞춤형 배차 안내문 포맷팅.
- `launchDispatchSms(delivery, options)`:
  - iOS(`&body=`) vs Android/PC(`?body=`) 구분자 분기.
  - 클립보드 안전 선제 복사(`copyToClipboard`) 병행 처리(앱 미연동 대비 폴백).
  - 스마트폰 기본 SMS 앱 딥링크 호출 (`window.location.href = smsUrl`).

### 2단계: 모바일 배차 대장 (`src/mobile/pages/MobileDispatchList.tsx`) 연동
- 기사 배정 모달 내:
  - 기사 배정 확정 시 원클릭 `[배정 확정 및 배차문자 발송]` 버튼 추가.
- 배차 목록 카드 내:
  - 기사가 배정된(`driverContact` 존재) 카드에 `[전화]` 버튼 옆 **`[배차문자]`** 버튼 추가.
  - 클릭 시 즉시 기본 문자 앱 실행.

### 3단계: PC 배차 관리 (`src/pages/TruckDispatch.tsx`) 연동
- 배차 대장 상세/카드에 `[기사 문자]` 버튼 배치.
- PC 클릭 시 배차 안내문 클립보드 자동 복사 + 토스트 안내 표출.

### 4단계: 빌드 및 프로덕션 배포 검증
- `tsc -b && vite build` 0 Type Error 검증.
- Vercel 프로덕션 배포 및 정상 동작 확인.

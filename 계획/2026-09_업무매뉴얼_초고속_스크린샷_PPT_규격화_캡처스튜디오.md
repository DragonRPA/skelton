## 1. 프로젝트 목적 및 핵심 워크플로우

> **"업무매뉴얼 제작을 위해 반복되는 수백 장의 캡처, 리사이즈, 번호 도형 그리기, PPT 붙여넣기 작업을 단축키 F9/F10 및 자동 규격화로 90% 이상 단축한다."**

### 🎯 3단계 직관 워크플로우
1. **`F9` (캡처 시작)**:
   - 어디서든 즉시 가상 데스크톱 전체화면 오버레이 가동.
   - 자석 창/컨트롤 자동 감지, 8방향 리사이즈 핸들, 방향키 1픽셀 미세조정, 실시간 돋보기/크기 툴팁, 직전 영역 재사용(`R`).
2. **실시간 주석 및 스타일 편집 (작업대 유지)**:
   - 원클릭 자동 증가 번호 스탬프(`①, ②, ③...`), 마우스 드래그 위치 이동, 스마트 번호 재정렬.
   - 텍스트 라벨 박스 생성 및 자유 드래그 배치, 인라인 편집.
   - 강조 박스 테두리 그리기 및 마우스 커서 합성 토글.
   - 실행 취소(`Ctrl + Z`), 마우스 우클릭 삭제, 번호 리셋.
   - 새 캡처(`F9`) 전까지 작업 세션 100% 지속 보존.
3. **`F10` (슬라이드 내보내기)**:
   - PPT 표준 가로폭(기본 960px)으로 Lanczos 초고화질 자동 리사이즈 및 일체형 합성.
   - 현재 열려 있는 PowerPoint의 새 슬라이드에 자동 생성 및 중앙 삽입.
   - Windows 네이티브 DIB 클립보드 동시 주입 (`Ctrl + V` 지원).
   - 로컬 작업 폴더에 `Step_001.png` 무손실 자동 백업 저장.

## 2. 모듈별 상세 설계 및 기술 스택

1. **글로벌 핫키 매니저 (`HotkeyManager`)**:
   - Windows API `RegisterHotKey` (ctypes) 활용.
   - `F9` (0x78) ➔ 캡처 오버레이 호출.
   - `F10` (0x79) ➔ 슬라이드 내보내기 호출.
2. **오버레이 캔버스 (`CaptureOverlayWidget`)**:
   - `PyQt5.QtWidgets.QWidget` (`Qt.FramelessWindowHint | Qt.WindowStaysOnTopHint | Qt.WA_TranslucentBackground`).
   - `win32gui.WindowFromPoint`, `GetWindowRect` 기반 창 자석 스냅.
   - 8방향 사각형 핸들 조작, 키보드 방향키 이동/크기 조절.
3. **스튜디오 에디터 & 주석 엔진 (`ManualCaptureStudioApp`)**:
   - 원본 이미지 위에 번호 스탬프, 텍스트 라벨, 강조 박스 관리.
   - `QPainter` 고품질 렌더링 + `Pillow` Lanczos 정밀 리사이즈.
4. **PowerPoint COM 브리지 (`PowerPointBridge`)**:
   - `win32com.client.Dispatch("PowerPoint.Application")`
   - 활성 프레젠테이션 탐지 ➔ 슬라이드 생성 ➔ AddPicture 중앙 배치.
5. **클립보드 & 파일 백업 매니저**:
   - 네이티브 DIB 포맷 클립보드 주입.
   - 세션별 날짜 폴더(`captures_YYYYMMDD/`) 생성 및 순번 저장.

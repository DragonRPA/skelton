## 1. 개발 목표 및 개요

1. **목표**:
   - 웹 브라우저의 폰트/레이아웃 렌더링 한계 및 대용량 메모리 부하를 해결하기 위해, 로컬 PC에서 상주하는 **초경량 사이드카 에이전트(Local Sidecar Agent)**를 구축한다.
   - 직원이 웹 ERP(PC 또는 모바일)에서 서류 발행을 요청하면, 사내 에이전트가 마이크로소프트 엑셀 원본 서식에 직접 셀 값을 주입하고 정품 PDF로 출력하여 로컬 문서고에 자동 아카이빙 및 클라우드 결합을 완결한다.
2. **핵심 설계 원칙**:
   - **콜사인 체계**: 로그인 아이디(`loginId`)를 에이전트 고유 콜사인으로 사용 (다중 기기 시 `loginId-2` 자동 확장).
   - **중앙 메시지 큐**: Supabase Realtime 기반 `document_jobs` 큐 운용 (모바일/원격 지시 ➔ 사무실 PC 무인 생산).
   - **마스터-레플리카 스토리지**: 구글 드라이브는 원형 마스터, 로컬은 워킹 복제본으로 운용하며 `md5Checksum`으로 내용 갱신 자동 감지.
   - **안전성 & 보안**: 엑셀 임시 복사본 작업으로 파일 잠금 충돌 0%, 좀비 프로세스 방지, 디지털 진본성 마킹, DPAPI 암호화.

## 2. 세부 개발 단계 및 구현 명세

### 1단계: DB 스키마 DDL 구축 (`schema.sql`)
- `agent_registry`: 에이전트 콜사인, 사용자 매핑, 마스터 권한, 생존신호(Heartbeat)
- `document_jobs`: 문서 생산 작업 대기열 (작업 상태, 대상 콜사인, 원자적 락, 결과 파일)

### 2단계: 로컬 경량 에이전트 데몬 구현 (`agent/`)
- `agent/agent.js` / `agent/agent.ts`:
  - 로그인 인증 및 콜사인 자동 등록, 30초 주기 하트비트 전송
  - Supabase Realtime / 큐 폴링 감시
  - 구글 드라이브 백그라운드 미러링 (`DriveMirror/`) 및 `md5Checksum` 기반 자동 갱신
  - 엑셀 조작 및 PDF 렌더링 엔진 (임시 파일 격리 처리)
  - 로컬 문서고 자동 아카이빙 (`D:\기연리프트_문서고\YYYY-MM\`)
  - 로컬 HTTP API 서버 내장 (웹 프론트엔드와 실시간 상태 핑퐁)
- `agent/start-agent.bat`: 원클릭 실행 배치 스크립트

### 3단계: 프론트엔드 연동 (`GoogleConfig.tsx`, `AppContext.tsx`)
- 웹 화면 상단 에이전트 실시간 연결 상태 배지 (`🟢 에이전트 연결됨 (콜사인: admin)` / `🔴 미연결`)
- 에이전트 원클릭 다운로드 및 설치 가이드 팝업
- 계약 서류 팩 발행 시: 에이전트 활성화 시 큐 기반 초고속 생산 ➔ 브라우저 Fallback 듀얼 모드 지원

## 3. 검증 및 배포 기준

1. 로컬 에이전트 가동 시 Supabase `agent_registry`에 콜사인이 정상 등록되고 프론트엔드에서 녹색 신호등이 점등되는지 검증.
2. 모바일/웹에서 작업 요청 시 에이전트가 1~2초 내에 엑셀 주입 및 PDF 생산 후 로컬 폴더에 저장하는지 검증.
3. TypeScript 컴파일 통과 및 단축어 "ㄹㅇ"에 따른 원격 푸시 완결.

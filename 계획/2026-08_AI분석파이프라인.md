## 의도한 설계

4단계 파이프라인으로 설계:

```
1단계: 음성 → 텍스트 (STT)         Faster-Whisper + RTX 5080 GPU
2단계: 텍스트 → 구조화 JSON (LLM)  Gemma / Qwen / Gemini 멀티 엔진
3단계: 다중 결과 앙상블 병합         16스레드 병렬 처리
4단계: AI 군집화 → 대시보드 생성    LLM 온톨로지 + Chart.js HTML
```

---

## 핵심 설계 원칙 (계획 시점)

1. **무손실 보존**: 어떤 엔진을 쓰든 원본 파일을 덮어쓰지 않는다
2. **다중 엔진 비교**: 단일 엔진의 오류를 앙상블로 교정한다
3. **로컬 우선**: 클라우드 의존 없이 로컬 GPU로 완전 자립 처리
4. **표준 온톨로지**: 7대 증상 계통 × 5대 조치 유형으로 전사 통일

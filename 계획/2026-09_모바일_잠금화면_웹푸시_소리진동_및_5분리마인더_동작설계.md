## 1. 스마트폰 잠금화면(Screen Lock) 수신 시 실제 동작

### 1.1 소리와 진동이 울리는가? (Yes)
- **안드로이드 (삼성 갤럭시 등)**:
  - Web Push 수신 즉시 꺼져 있던 검은 화면이 켜지며(Screen Wake-up), 시스템 기본 알림음과 진동이 울림.
  - 사용자가 무음 모드로 설정하지 않은 한 100% 소리 재생.
- **아이폰 (iOS 16.4+ PWA)**:
  - APNs 페이로드의 `sound: "default"` 속성에 의해 화면이 켜지면서 기본 알림음("삼중음/팅")과 햅틱 진동이 울림.
  - 아이폰 좌측 물리 무음 스위치가 켜져 있으면 진동만 발생.

### 1.2 잠금화면에서 어떻게 보여지는가? (UI 카드 형태)
- 카카오톡, 문자메시지와 동일하게 잠금화면 중앙에 푸시 카드 형태로 렌더링됨:
  ```text
  ┌──────────────────────────────────────────────────────────┐
  │ 🏗️ 키은리프트 FIELD                              지금   │
  │ 🚨 [출고요청 미접수] 포스코이앤씨 2대 대기 (5분 경과)       │
  │ 상차: 모현 주기장 ➔ 하차: 송도 3공장 | 영업: 김과장       │
  │ [즉시 접수] (터치 시 생체인식 해제 후 앱으로 직결)        │
  └──────────────────────────────────────────────────────────┘
  ```

### 1.3 5분 간격 재발송 시 동작 (Tag 기반 알림 갱신)
- 5분 뒤에도 미접수 상태라면 2회차 푸시 발송:
  - `tag: "dispatch-order-" + orderId` 옵션을 사용하여 잠금화면에 무한대로 알림이 도배되는 것을 방지.
  - 기존 알림 카드가 갱신("10분 경과")되면서 다시 화면이 켜지고 소리/진동이 울려 피로도를 줄이면서도 확실히 재인지 유도.

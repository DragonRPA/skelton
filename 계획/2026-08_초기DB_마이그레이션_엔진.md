# [계획] 레거시 엑셀 1개 파일 기반 전사 초기 DB 일괄 마이그레이션 엔진

> **일자**: 2026-08-31  
> **프로젝트**: Kiyeun_Lift ERP  
> **연결 링크**: [경험: 초기DB 마이그레이션 엔진](../경험/2026-08_초기DB_마이그레이션_엔진.md)

---

## 1. 배경 및 목적
- 신규 고객사에 고소작업대 렌탈 ERP를 개시할 때, 기존에 수기로 관리하던 현황 엑셀 파일(5개 시트, 6,450여 행)을 분석하여 시스템 DB 스키마에 맞춰 일괄 업로드하고 완벽한 운영 시작점을 형성.

## 2. 핵심 설계 계획
1. **O-1 (가상 자산 인정)**: 가상 관리번호 및 임시 자산 31건도 `assets` 대장에 정상 자산(`isVirtual: true`)으로 등록.
2. **O-2 (정규식/포맷 캐스팅)**: 날짜 시리얼(46235 ➔ 2026-08-01), 현장명 괄호 메모(`(7/18)하차`), 담당자 직급 정규식 분리, 통화기호 정제.
3. **O-3 (종료 계약 일할 반영)**: '종료' 계약 라인을 `status: 'COMPLETED'`로 적재하고 8월 1일부터 반납일까지의 일할 렌탈료를 청구서에 반영.
4. **O-4 (고속 파이프라인)**: 인메모리 고속 처리 + 200건 단위 청킹(Chunking) 분할 전송 + 멱등한 `onConflict` Upsert.
5. **3단계 안전 파이프라인**:
   - Step 1: 전체 20개 테이블 JSON 일괄 백업
   - Step 2: 외래키 역순 안전 초기화 (2중 확인 모달, admin 계정 보존)
   - Step 3: 8단계 DAG 순차 적재 + Audit Trail 3종 세트 + 4대 대차대조 ₩0 검증서 표출

## 1. 단계별 실행 계획 (Execution Steps)

### Step 1: UIA 코어 엔진 신설 (`engine_uia.h`, `engine_uia.c`)
- Windows `UIAutomationCore.dll` C COM 인터페이스 바인딩.
- 요소 검색(이름, 자동화 ID, 컨트롤 타입), 패턴 실행(Invoke, Value, Toggle, Selection, ScrollIntoView), 상태 대기(`CurrentIsEnabled`).
- 실시간 마우스 좌표 기반 UIA 요소 스니퍼(`UIA_GetElementFromPoint`).

### Step 2: 시나리오 구조체 및 스텝 확장 (`engine_scenario.h`, `engine_scenario.c`)
- 6종 UIA 스텝 열거형 추가:
  - `STEP_UIA_CLICK`
  - `STEP_UIA_SET_TEXT`
  - `STEP_UIA_TOGGLE`
  - `STEP_UIA_SELECT`
  - `STEP_UIA_WAIT_STATE`
  - `STEP_UIA_AUTO_WIZARD`
- `MacroStep` 필드 확장 및 JSON 직렬화/역직렬화 연동.

### Step 3: 메인 UI 개편 및 UIA 전용 도구 그룹 바 독립 배치 (`ui_main.c`)
- 메인 윈도우 우측 패널에 독립된 [Row 3: UIA 전용 도구 바] 신설:
  - `[UIA 스파이]`, `[UIA 클릭]`, `[UIA 텍스트입력]`, `[UIA 체크설정]`, `[UIA 콤보선택]`, `[UIA 상태대기]`, `[UIA 마법사통과]`
- `UI_ShowUiaStepDialog`: UIA 스텝 추가/수정용 모달 다이얼로그.
- `UI_ShowUiaSpyDialog`: 실시간 초록색 하이라이트 박스를 동반한 인터랙티브 UIA 스파이 피커.
- `PlaybackThreadProc`: UIA 스텝 실행 핸들러 연동.
- `UI_EditStep`: 더블클릭 시 UIA 스텝 수정 창 호출 연동.

### Step 4: 빌드 파이프라인 연동 (`build.bat`)
- `engine_uia.c` 컴파일 및 `ole32.lib`, `oleaut32.lib`, `uiautomationcore.lib` 링크.
- 0 경고 0 에러 무결점 바이너리 검증.

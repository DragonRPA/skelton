## 솔직한 회고 — 다시 한다면 무엇을 다르게 하겠는가

### 1. 온톨로지를 처음부터 데이터와 함께 설계했을 것

계획 단계에서 "7대 증상 계통"을 먼저 선언하고 데이터에 맞췄다.
다시 한다면 — 실제 어구 1,000개를 먼저 추출하고, 거기서 자연스럽게 계통을 귀납적으로 도출했을 것이다.
온톨로지는 이상에서 내려오는 것이 아니라 현장에서 올라와야 한다.

### 2. default 반환값을 "미분류"로 처음부터 설정했을 것

임시로 SUCTION을 default로 썼다가 몇 달치 통계가 왜곡됐다.
코드에서 "임시"는 존재하지 않는다. 임시는 영구가 된다.

### 3. LLM JSON 불안정성을 처음부터 설계에 반영했을 것

LLM이 안정적으로 JSON을 반환할 것이라 가정했다.
처음부터 "LLM은 실패한다"를 전제로 부분 파싱 + 재시도 + 개별 격리 구조를 설계했어야 한다.

### 4. SSOT를 처음부터 단일 모듈로 설계했을 것

analytics_builder와 taxonomy_clusterer에 동일 규칙이 이중으로 생긴 것은
"일단 여기서도 쓰자"는 편의에서 시작됐다.
처음부터 "분류 규칙은 taxonomy_clusterer만 안다"는 원칙을 세웠으면 60줄의 기술 부채가 생기지 않았다.

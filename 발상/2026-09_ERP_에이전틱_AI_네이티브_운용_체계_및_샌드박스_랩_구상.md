## 1. 발상 배경 및 사장님 핵심 화두 (Inception Context)

> **"타 프로젝트에서 영감을 받은 것으로써, 에이전틱 AI 들이 우리 시스템을 잘 활용할 수 있게 도와줄 방법을 찾아서 기획안을 만들어봐. 필요하다면 현재 메뉴 기능들은 유지해놓고 테스트용 메뉴를 신설해서, 아주 많은 테스트를 해봐도 좋겠어. 어떻게 얼마나 편리해지는지 아주 궁금하네."**

타 데스크톱 프로젝트(매뉴얼 스튜디오)의 UIA/MCP 에이전트 친화적 설계 발상에 이어, **웹 기반 ERP 시스템 역시 에이전틱 AI(Claude Cowork, OpenAI Operator, ReAct 에이전트 등)가 완벽히 이해하고 조작할 수 있는 'Agent-Native ERP'로 진화**해야 한다는 통찰이다.

## 2. ERP 에이전틱 AI 운용 4대 핵심 축 (4 Architectural Pillars)

### ① 기계 판독형 도메인 카탈로그 (`AGENTS.md` / `erp_agent_manifest.json`)
- 에이전트가 66개 테이블, 44개 메뉴, 데이터 모델과 외래키 구조, 상태 머신을 0초 만에 완벽히 이해할 수 있는 LLM 토큰 최적화 JSON 스펙 제공.

### ② 시맨틱 액션 툴 매니페스트 (MCP & Tool Calling API Gateway)
- 불안정한 브라우저 픽셀 클릭/DOM 셀렉터 탐색을 전면 탈피.
- 에이전트가 함수 호출(Tool Calling) 하나로 배차 발행, 검수 승인, 소모품 일괄 업로드, 대차 교체 등의 비즈니스 액션을 즉시 원자적(Atomic)으로 실행.

### ③ 전사 표준 헌장 불변식 가드레일 (Charter Guardrails Interceptor)
- AI가 어떤 의사결정이나 액션을 내리더라도 시스템 헌장(헌장 1.3 출고시 RENTED 강제, 헌장 2.3 단일 EXCHANGE 왕복배차 강제, 헌장 4.1 일할 매출 기여액 1원 일치, 헌장 5.2 무음 실패 방지)을 시스템 미들웨어 수준에서 100% 강제 검증하여 무결성을 수호.

### ④ 에이전틱 AI 샌드박스 랩 신설 (`AgenticAiLabPage`)
- 기존 44개 운영 메뉴를 100% 온전히 보존하면서, 에이전틱 AI를 마음껏 구동하고 20~50회 연속 스트레스 테스트를 수행할 수 있는 전용 실험실 메뉴 신설.
- 자연어 프롬프트 콘솔, ReAct 비주얼 타임라인, 인간 대비 편의성/효익(시간 99% 단축, 클릭 98% 절감) HUD 대시보드를 제공하여 혁신적 편익을 실시간 입증.

## 3. 기대 효익 (Expected Value)

1. **임직원 피로도 극적 절감**: 복잡한 다단계 입력 작업을 자연어 한 줄("2월 미수금 500만원 이상 거래처 일괄 회수 배차 잡고 소모품 50개 매입해줘")로 3초 만에 완결.
2. **비즈니스 무결성 100% 보존**: AI의 환각이나 실수로 인한 도메인 규칙 위반을 헌장 가드레일이 원천 차단.
3. **타 프로젝트로의 수평 전파**: 매뉴얼 스튜디오와 기연리프트 ERP가 상호 에이전틱 표준을 공유하며 전사 소프트웨어의 에이전트 네이티브 표준화 완성.

## 1. 발상 배경
- TMap의 내비게이션 길안내 스킴(`tmap://route`)은 목적지의 위도/경도 숫자 좌표(`goalx`, `goaly`)가 누락되면 경로 탐색을 개시하지 못하고 메인 홈 화면만 열리는 기술적 제약이 존재함.
- 일상 생활에서 공유받는 티맵 링크(`surl.tmap.co.kr`)는 티맵 서버의 사전 등록 POI 좌표를 내포하고 있어 즉시 길안내가 실행됨.
- ERP DB에는 문자열 도로명 주소만 저장되어 있으므로, 내비게이션 호출 직전 백그라운드에서 비동기로 주소를 위경도 좌표로 즉시 변환(Geocoding)하여 `goalx`, `goaly`를 TMap에 전달하면 사용자의 추가 조작 없이 즉각 길안내가 시작될 수 있음.

## 2. 구상 아키텍처
1. **지오코딩 엔진 옵션**:
   - 옵션 1: SK Open API TMap `fullAddrGeo` (월 30만 건 무료, TMap 자체 POI 노드와 100% 일치)
   - 옵션 2: 국토교통부 브이월드(VWorld) 국가공간정보 오픈 API (무료 도로명/지번 주소 좌표 변환)
   - 옵션 3: 카카오 로컬 REST API (`/v2/local/search/address.json`)
2. **동작 시퀀스**:
   - [T맵 열기] 버튼 터치 ➔ 0.1초 백그라운드 API 호출 ➔ `newLon`, `newLat` 획득 ➔ `tmap://route?goalname={명칭}&goalx={lon}&goaly={lat}` 즉각 실행.
   - 변환 실패 또는 타임아웃(0.3초) 시 기존 검색 스킴(`tmap://search`) 및 클립보드 복사로 안전한 2중 폴백.

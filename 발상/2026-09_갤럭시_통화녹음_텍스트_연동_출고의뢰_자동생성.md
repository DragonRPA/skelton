# 갤럭시 통화녹음 텍스트(Call Transcript) 연동 출고의뢰 자동 생성

- **일시**: 2026-09-04 15:39
- **작성자**: 사장님 발상 감지 (Antigravity 시스템 자동 기록)
- **맥락**: 최신 갤럭시 스마트폰(One UI 6.1+, Galaxy AI)의 통화 녹음 자동 텍스트 변환(Call Transcript) 기능을 ERP 출고의뢰 파이프라인과 결합할 수 있는지에 대한 기술적 실현 가능성 및 실무 적용 방안 검토.

---

## 1. 발상 배경 및 도메인 혁신성
- **렌탈 영업의 본질**: 고소작업대 렌탈 계약 및 출고 요청의 90% 이상은 현장 소장/반장과 영업사원 간의 **전화 통화**를 통해 발생함.
- **기존 고통**: 통화 종료 후 운전 중이거나 이동 중에 들었던 제원(1930, 2632 등), 수량, 납품일시, 현장 주소, 특이사항을 메모지에 적거나 기억에 의존해야 하여 누락/오발주 위험이 큼.
- **발상 핵심**: 통화가 끝나면 갤럭시 AI가 자동으로 생성해 둔 "통화 녹음 텍스트"를 ERP로 인입시켜, 기존에 구축한 증분 자연어 파서(`voiceOrderDraftService`)로 즉시 계약서 및 출고의뢰서로 자동 치환함.

---

## 2. 안드로이드 OS 보안 샌드박스와 실현 가능성 분석

### 제약사항 (Web Browser Sandbox)
- 기연리프트 시스템은 PWA(Web)로 동작하므로, 안드로이드의 보안 정책(Scoped Storage)상 웹앱이 사용자의 승인 없이 `/Recordings/Call/` 폴더나 삼성 음성녹음 앱 DB를 백그라운드에서 은밀히(Silent) 자동 폴링하는 것은 차단됨.

### 실현 가능한 3대 연동 아키텍처
1. **방안 1: 안드로이드 공유하기(Web Share Target API) 연동 [강력 추천]**:
   - 갤럭시 통화 요약/텍스트 화면에서 `[공유]` 버튼 터치 ➔ 공유 대상 앱 목록에 **'기연리프트 (출고의뢰 생성)'** 노출 ➔ 터치 1번에 ERP로 전문 인입 및 폼 자동 완성.
   - 네이티브 앱 설치 없이 PWA `manifest.json` 설정만으로 즉시 작동.
2. **방안 2: 원터치 클립보드 붙여넣기 (Clipboard Paste Integration)**:
   - 갤럭시 통화 텍스트 창에서 '텍스트 복사' 터치 ➔ ERP 출고의뢰 화면 진입 시 `[📋 통화 텍스트로 채우기]` 버튼 원터치 ➔ `navigator.clipboard.readText()`로 즉시 파싱 및 자동 채움.
3. **방안 3: 안드로이드 네이티브 백그라운드 서비스 (Companion APK)**:
   - 파일 감시 권한을 가진 초경량 네이티브 헬퍼 앱을 두어, 통화 녹음 텍스트 파일 생성 시 사내 Supabase DB로 자동 업로드.

---

## 3. 기대 효익 (헌장 1.1 준수)
- 통화 종료 후 단 1~2번의 터치만으로 통화 중 오간 계약 내용(거래처, 현장, 모델, 대수, 일시, 담당자)이 100% 무누락 DB 적재 및 계약/배차 건으로 완결됨.
- 임직원의 입력 노력을 '제로(Zero)'에 가깝게 줄이는 궁극의 실무 편익 달성.

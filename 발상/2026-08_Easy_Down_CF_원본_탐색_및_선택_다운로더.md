   - 복잡한 런타임 설치 없이 더블 클릭 한 번으로 실행되는 독립형 단일 .exe 바이너리 요구.
   - 실행 파일의 용량이 최소화되어 어디서든 즉시 배포 및 실행이 가능해야 함.

## 2. 핵심 발상 및 아키텍처 (Core Concept)

### 2.1 초경량 단일 실행 파일 아키텍처
- **언어 및 런타임**: C# .NET NativeAOT (또는 경량 네이티브 컴파일)를 사용하여 런타임 의존성 없는 수 MB 수준의 초경량 단일 .exe 생성.
- **UI/UX**: 전사 표준 헌장 준수 (무수식어 건조한 명사·동사 UI, 상하 스택 폼, 줄바꿈 방지). R2 설정 관리, 디렉토리/파일 계층 트리 실시간 탐색, 체크박스 다중 선택 및 다운로드.

### 2.2 S3 호환 API 및 Direct CDN 다운로드 파이프라인
- **메타데이터 및 목록 조회**: Cloudflare R2의 S3 호환 ListObjectsV2 API로 버킷 내 트리 계층 조회.
- **고속 다운로드**: Public Custom Domain 또는 S3 GetObject API를 활용한 멀티스레드 비동기 스트리밍 다운로드.

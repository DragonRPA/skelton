## 1. 발상 배경 및 현장 문제의 본질 (Problem Context)

### 1.1 영업 현장의 현실적 고충 (Inbound Call Pain Point)
- 고소작업대(렌탈) 영업사원은 업무 시간의 상당 부분을 차량 운전, 외근, 현장 실사, 고객사 미팅 등으로 보낸다.
- 이 상태에서 현장 소장, 구매팀장 등으로부터 불시에 인바운드 문의 전화가 쏟아진다:
  > *"이 과장, 지금 26피트 몇 대 있어요? 내일 아침에 바로 2대 나가야 하는데."*
  > *"모현 주기장에 32피트 당장 출고 가능한 거 있습니까?"*
  > *"19피트 단가랑 재고 확인 좀 바로 해줘요."*
- **현재 시스템의 한계**:
  1. **PC 접속 불가**: 이동 중/통화 중에 노트북을 켜서 ERP에 접속할 수 없다.
  2. **모바일 리스트의 가독성 한계**: 현재 모바일 웹/PWA가 존재하더라도 수십~수백 대의 개별 장비(K10001, K10002...) 카드 리스트를 스크롤하면서 세어볼 여유가 없다.
  3. **통화 중 3초 이내 판단 필수**: 고객과의 통화 중에는 단 3초 안에 "네, 26피트 4대 임대 가능하고 내일 즉시 출고됩니다"라고 답해야 영업 기회를 선점할 수 있다.
  4. **주기장/관리부서 전화 의존**: 결국 전화를 끊고 주기장 반장님이나 사무실에 재고 확인 전화를 걸고 다시 고객에게 콜백하는 비효율과 기회 손실이 반복된다.

## 2. 핵심 발상 및 시스템 구상 (Core Ideas)

### 💡 구상 1: 모바일 원터치 『3초 스캔 가용재고 매트릭스 (Quick Stock Matrix)』
- **형태**: 모바일 ERP PWA 내 '가용자산' 탭 첫 화면을 **"규격(ft) × 주기장별 재고 신호등 대시보드"**로 전면 개편.
- **주요 UI 컴포넌트**:
  1. **작업높이(ft)별 가용 블록 카드**:
     - `19ft (1330/3215)`: 🟢 **8대 가용** (입고예정 +2대)
     - `26ft (0812/3219)`: 🟢 **12대 가용** (입고예정 +1대)
     - `32ft (1012/3246)`: 🟡 **3대 가용** (주의)
     - `40ft (1212)`: 🔴 **0대 (품절)** [단, 타사 전대 조회 가능]
  2. **원터치 탭 시 상세 팝업 (1초)**:
     - 해당 ft 블록을 누르면: 보관 주기장(본사 모현 / 제2야적장 / 협력사), 추천 모델, 기준 단가(월/일) 즉시 확인.
  3. **반납(입고) 예정 바운스**:
     - 현재 재고가 0대이더라도 "오늘/내일 반납 예정 2대"를 즉시 알려주어 출고 릴레이 영업 가능.

### 💡 구상 2: 카카오톡 알림톡 / 슬랙 챗봇 간편 쿼리 (Hands-Free / Chatbot)
- **개념**: 브라우저나 앱 로그인조차 번거로운 운전·통화 상황을 위해 사내 카카오톡 채널 또는 봇 연동.
- **동작**:
  - 카톡방에 `26` 또는 `재고` 입력(또는 음성 입력) ➔ 1초 내 즉시 답장:
    ```
    [기연리프트 실시간 가용재고]
    - 26ft: 12대 (모현주기장: 9대, 제2주기장: 3대)
    - 월단가: 35만 | 일단가: 1.5만
    - 즉시 배차 가능 상태 (출고검수 통과)
    ```

### 💡 구상 3: 스마트폰 잠금화면 / 홈화면 실시간 위젯 (Widget)
- **개념**: 앱을 켜지 않고도 스마트폰 홈 화면이나 잠금 화면에 항상 고정으로 주요 규격별(19/26/32/40) 실시간 가용 재고 숫자가 위젯으로 실시간 갱신되어 상시 노출됨.
- **효과**: 전화 오면 화면만 켜서 잠금화면/홈화면을 보고 즉시 통화 대응.

### 💡 구상 4: 자사 결품 시 『타사 전대/임차 가능 풀 원클릭 조회』 연동
- 자사 자산이 0대인 경우, 영업사원이 당황하지 않고 동일 권역 내 원사/협력사(타사 전대 장비 풀) 가용 여부와 기준 원가를 즉시 확인하여 "타사 대차 출고"로 즉시 연결 (헌장 2.1 영업과 출고 R&R 준수).

## 3. 기대 효익 (Expected Benefits)

1. **영업 수주율 극대화 (골든타임 사수)**: 문의 전화 중 3초 안에 즉답하여 고객 이탈 방지.
2. **주기장-영업 간 불필요한 확인 전화 90% 감축**: 현장 소통 피로도 제로화.
3. **입고 예정 장비 연계 출고율 향상**: 주기장 체류 시간(야적 손실) 최소화.

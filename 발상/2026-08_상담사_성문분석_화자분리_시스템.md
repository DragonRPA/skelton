# [발상] 상담사 사전 성문분석 기반 실시간 화자분리 시스템 (Speaker Diarization)

## 1. 발상 배경 (Context)

현재 Space Advisor는 실시간 Web Speech API 및 스트리밍 STT를 통해 통화 음성을 전사하고 고장 키워드를 감지하여 표준 조치법을 어시스트하고 있다.  
그러나 현장 콜센터 환경에서는 **상담원의 안내 음성과 고객의 고장 설명 음성이 단일 모노 오디오로 섞여 들어오기 때문**에 아래와 같은 구조적 노이즈가 발생할 수 있다:

1. 상담사의 인사말, 되묻기, 맞장구 멘트가 AI 진단 룰에 불필요하게 섞여 들어가는 문제
2. 상담 완료 후 배차/이관 대장 기록 시 "고객의 주장"과 "상담사의 1차 조치 안내"가 분리되지 않고 통짜로 묶이는 문제

이에 따라, **"회사의 상담원이 여러 명일 때, 상담원의 목소리를 사전에 30초 녹음/학습시켜 성문 분석(Voiceprint Analysis)을 통해 대화 중 상담사와 고객의 발화를 실시간으로 분리해낼 수 있는가?"**라는 혁신적 시스템 발상이 제안되었다.

## 2. 핵심 아이디어 및 시스템 아키텍처

```
[ 1. 상담사 성문 등록 (사전 1회) ]
상담사 30초 표준 스크립트 녹음 ➔ 딥러닝 임베딩 (ECAPA-TDNN) ➔ 512차원 성문 벡터 DB 저장
                                                                            │
[ 2. 실시간 통화 음성 수신 ]                                                 │
고객 ↔ 상담사 실시간 대화 스트림 수신 (0.5초 단위 청크)                       │
                                                                            │
[ 3. 코사인 유사도 (Cosine Similarity) 실시간 판별 ]                         │
실시간 오디오 청크 벡터 ↔ 로그인된 상담사 성문 벡터 비교 ◄───────────────────┘
• 유사도 ≥ 0.82 ➔ [상담사 이지은] (우측 정렬 / 푸른색 말풍선)
• 유사도 < 0.70 ➔ [고객사 발화] (좌측 정렬 / 흰색 말풍선 ➔ AI 진단 룰 주입)
```

### 세부 구성 방안
1. **사전 성문 등록 (Speaker Enrollment)**:
   - 상담사 초기 프로필 등록 시 30초 표준 문장 녹음.
   - `SpeechBrain (ECAPA-TDNN)` 또는 `PyAnnote 3.1` 딥러닝 모델로 성문 특징 벡터 추출 후 DB 테이블(`counselor_embeddings`)에 보관.
2. **실시간 발화자 분리 (Target Speaker Diarization)**:
   - 통화 중 로그인한 상담사의 성문 벡터와 실시간 음성을 비교하여 95~98% 정확도로 화자 분리.
3. **듀얼 트랙(Dual-Track) 콜센터 연동**:
   - CTI 소프트폰 환경이 지원될 경우 2채널(스테레오) 하드웨어 분리를 기본으로 하되, 단일 모노 마이크 환경에서는 위 AI 성문 분석 엔진을 Fallback으로 작동.

## 3. 기대 효익 및 가치 (System Core Mission)

1. **AI 진단 무오류성 달성**:
   - 고객 발화만 순수하게 필터링하여 AI 룰베이스 및 LLM에 주입하므로 상담사 잡음으로 인한 오진단 0% 달성.
2. **상담사 QA(품질 평가) 자동화**:
   - 상담사가 필수 법적 고지(ARS 녹음 안내), 표준 인사말, 자가조치 유도 스크립트를 제대로 이행했는지 음성 단위 자동 채점.
3. **현장 출장 배차 및 이력 기록 100% 무결성**:
   - `visits` 대장에 `[고객 주장 증상]`과 `[상담사 1차 조치 내역]`이 1초의 오차 없이 분리 저장.

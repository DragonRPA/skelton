## 1. 발상 배경 및 문제의식
- 유튜브 영상(MiniMax H3 실전 분석)에서 제시된 오픈소스 멀티모달 비디오 생성 모델은 우수한 영상 품질과 오디오 동기화, 캐릭터 교체(Omni Reference) 기능을 지원함.
- 그러나 일반 사용자가 직접 ComfyUI 노드 세팅, SageAttention 커널 컴파일, 복잡한 마크다운 프롬프트 규칙 수동 작성, 오디오 분리/재합성 후처리를 매번 수작업으로 진행하는 것은 진입 장벽이 매우 높음.
- 로컬 경량 SLM(Ollama Qwen 2.5 7B)을 전처리기로 붙여 사용자 자연어를 정규 마크다운으로 자동 변환하고, Headless ComfyUI API 및 FFmpeg 후처리를 단일 독립실행형 데스크톱 어플리케이션으로 캡슐화하면 "최소 조작으로 최대 영상 생산성(최대 편익)"을 달성할 수 있음.

---

## 2. 핵심 발상 아이디어
1. **프롬프트 자동 마크다운 규격화**: 사용자의 1줄 자연어/아이디어를 MiniMax H3 전용 마크다운 계층 구조(Scene, Subject, Environment, Camera & Motion, Negative)로 로컬 SLM이 실시간 자동 확장.
2. **SageAttention v2 기반 추론 가속 캡슐화**: 생성 시간을 35~40% 단축하는 최적화 커널을 백엔드에 내장하여 VRAM 12GB~24GB 하드웨어별 최적 프리셋 제공.
3. **무누락 비동기 태스크 큐 및 오케스트레이션**: SQLite 기반 작업 대장과 상태머신을 통해 프롬프트 변환 -> ComfyUI 렌더링 -> FFmpeg 오디오 믹싱/최적화까지 논스톱 자동 완결.

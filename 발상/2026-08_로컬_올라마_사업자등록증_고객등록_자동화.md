## 💡 1. 발상 배경 및 문제의식 (Context)

- 신규 고객사가 계약을 체결하거나 견적을 요청할 때, 사업자등록증 사본(이미지/PDF)을 전달받는다.
- 기존 실무 방식: 담당자가 사업자등록증을 눈으로 보면서 **사업자등록번호, 상호(법인명), 대표자명, 사업장 주소, 업태, 종목, 개업연월일**을 ERP 폼에 하나하나 수작업으로 타이핑 입력.
- 문제점: 오타 발생 위험, 반복적인 번복 입력 피로도, 담당자 업무 시간 낭비.
- 클라우드 OCR API(네이버 CLOVA, 구글 Vision API 등)는 건당 유료 비용이 발생하고 고객사 사업자 정보가 외부 클라우드로 전송되는 보안 리스크가 존재함.

```mermaid
flowchart TD

    B --> C[🤖 사이드카 에이전트 KiyeunAgent.exe]

```

## 💰 3. 기대 편익 및 비즈니스 효익 (Business Value)

1. **임직원 입력 공수 95% 절감 (전사 헌장 1.1 최우선 개발 사명)**:
   - 파일 하나만 던지면 상호부터 사업자번호, 주소까지 0.5초 만에 자동 완성.
2. **완전 무료 (API 비용 0원)**:
   - 외부 유료 OCR API 결제 없이 사내 GPU/CPU에서 100% 무료 연산.
3. **완벽한 데이터 보안 (사내 로컬 처리)**:
   - 고객사의 중요한 사업자 정보가 외부 클라우드 서버로 단 1바이트도 유출되지 않음.
4. **계약 서류 팩 자동 생성과의 시너지**:
   - 추출된 사업자 정보가 계약서, 거래명세서, 견적서 엑셀 서식에 즉시 주입 연동.

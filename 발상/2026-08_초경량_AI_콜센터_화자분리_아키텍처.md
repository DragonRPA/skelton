# [발상] 초경량 AI 콜센터 및 로컬 화자분리 아키텍처

- **기록일시**: 2026-08-24 16:19
- **연결 프로젝트**: Space Consult Assist (DragonRPA)

## 1. 맥락 (Context)
소규모 콜센터를 위한 AI 코파일럿(실시간 STT + LLM 응대 가이드)을 구축하는 과정에서, "고객 목소리와 상담원 목소리의 분리(화자 분리)"가 필수적임을 확인했다. 하지만 기존 업계의 정석 아키텍처(SIP 트렁크 직접 계약 ➔ Asterisk PBX 서버 ➔ AudioSocket 추출)는 인프라 구축 비용과 네트워크 설정 기간이 너무 많이 소요되어 MVP 개발 원칙에 적합하지 않았다.

## 2. 핵심 발상 (Core Idea)
무거운 백엔드 통신 서버(PBX)를 완전히 배제하고, **상담원 PC(클라이언트 단)에서 완벽한 화자 분리와 AI 파이프라인을 100% 독립적으로 완성**하는 초경량 아키텍처를 고안했다.

1. **통신망 우회 (API/CPaaS 활용)**: 직접 통신사 망을 끌어오지 않고, ClawOps나 아톡비즈 같은 클라우드 기반 070 번호 및 소프트폰을 활용하여 최소 비용으로 통신 환경을 구축한다.
2. **CTI(발신자 팝업) 우회**: ClawOps의 Webhook API를 활용해, 전화 인입 시 로컬 FastAPI 서버로 고객 전화번호를 쏴주어 CRM(Space Advisor) 화면을 즉각 팝업한다.
3. **클라이언트 듀얼 스레드 화자 분리 (핵심)**:
   - **고객 채널 (수신음)**: Python WASAPI Loopback 캡처 (스피커 소리 낚아채기) ➔ 고객 음성 STT
   - **상담사 채널 (송신음)**: Python PyAudio 마이크 캡처 (상담원 목소리 낚아채기) ➔ 상담원 음성 STT
   이 2개의 스트림을 로컬 PC 백엔드에서 병렬로 분리 수집하여 프론트엔드로 전송하면, 복잡한 통신 서버 개입 없이도 엔터프라이즈급 화자 분리(Stereo) 대화록이 완성된다.

## 3. 기대 효과
- **시간 및 비용 절감**: 인프라 구축 기간 1개월 ➔ 1일 이내로 단축, 서버 유지보수 비용 제로.
- **최고의 호환성**: 통화 프로그램(소프트폰)의 종류에 종속되지 않는 범용적 수집.
- **AI 정확도 극대화**: LLM에게 완벽한 대화 문맥(고객 발화 vs 상담원 발화)을 제공하여 코파일럿의 응대 지침 정확도를 획기적으로 상승시킨다.

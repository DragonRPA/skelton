# 발상: 한컴 한글 COM 자동화를 RPA 워크플로우에 통합

**기록일**: 2026-08-23  
**사이클**: 발상

---

## 맥락

win_automation 패키지 개발 중 알집·한글 요소 킵 테스트를 진행하면서,  
한글이 HWP COM Object(`HWPFrame.HwpObject`)라는 공식 자동화 API를 제공한다는 사실을 확인함.

Excel의 xlwings처럼, 한글도 COM 기반으로 마우스/포커스 없이 문서를 완전 제어 가능.

## 발상 내용

### 핵심 개념
한글은 pywinauto UIA가 아닌 **COM 자동화 API**가 정답.

```
HWPFrame.HwpObject
├── HAction.Run("FileNew")          → 새 문서
├── HAction.Run("FileSaveAs")       → 다른 이름 저장
├── CreateAction("InsertText")      → 텍스트 삽입
├── GetPos() / SetPos()             → 커서 이동
├── HParameterSet.표/그림/...       → 표, 이미지 제어
└── RegisterModule("FilePathCheckDLL") → 보안 팝업 해제
```

### 실무 자동화 시나리오
1. **계약서 자동 생성**: DB에서 고객 정보 읽기 → 한글 템플릿(.hwt)에 필드 값 채워넣기 → .hwp 저장
2. **공공기관 문서 일괄 처리**: .hwp 파일 열기 → 특정 표 데이터 추출 → Excel/DB에 저장
3. **전자결재 자동화**: 한글 문서 작성 → PDF 변환 → 메일 발송

### API 입수처
- **한컴 디벨로퍼**: https://developer.hancom.com
  - `HwpAutomation.pdf` — 전체 메서드/속성

  - `ParameterSetTable.pdf` — 파라미터셋 정의

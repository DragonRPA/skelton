# 💡 [발상] 현장 임직원 실시간 무전기(Push-To-Talk / PTT) 다자간 음성 통신망 구상

- **일시**: 2026-09-04 12:35
- **제안자**: 대표이사 (이수용 사장님)
- **맥락**: 고소작업대 출고·배차·상차·현장 AS 업무 중 전화 통화의 한계(1:1 연결 대기, 작업 중 수신 조작의 번거로움)를 극복하고 다자간 실시간 음성 소통 필요성 대두

---

## 1. 문제의식 및 발상의 계기
- **전화 통화의 한계**:
  - 전화는 1:1 통화만 가능하여 지게차 상차 기사, 출고 검수자, 배차 기사 간의 삼자/다자간 동시 소통이 불가능함.
  - 전화 연결음 대기 시간이 길고, 현장에서 장갑을 끼고 작업 중일 때 전화를 일일이 받고 끊는 동작이 심각한 작업 중단을 유발함.
- **다자간 즉시 음성 소통(PTT)의 필요성**:
  - "3219번 2호차 상차 완료", "모현 주기장 40ft 진입 대기", "오산 현장 누유 긴급 출동" 등 3~5초 내외의 단문 음성 교환이 빈번함.
  - 별도의 무전기 하드웨어를 구매/휴대하지 않고, 임직원의 스마트폰(PWA 모바일 ERP) 하나로 필요할 때만 On/Off 켜서 다자간 무전 통신을 실현하고자 함.

---

## 2. 시스템 핵심 구상 (Core Ideas)
1. **개인별 On/Off 수신 대기 토글**:
   - 무전기를 켜둔(`ON`) 임직원에게만 실시간 음성이 스피커로 자동 방송됨.
   - 회의나 외근 중 방해가 되지 않도록 필요한 순간에만 원터치로 On/Off 제어.
2. **직무/상황별 채널 분리**:
   - `전사 공용 채널`: 긴급 공지 및 전사 공통 소통.
   - `출고/배차 채널`: 주기장 상차 지게차, 검수원, 배차 담당자 간 직결.
   - `현장 AS 채널`: 외근 출동 기사 간 고장 증상 상담 및 부품 수급 소통.
   - `영업 채널`: 외근 중 긴급 규격 재고 및 배차 가능 여부 질의.
3. **무전기 고유의 Push-To-Talk (PTT) UX**:
   - 엄지손가락으로 큼직한 PTT 버튼을 누르고 있는 동안 녹음, 손을 떼면 즉시 상대방들에게 자동 송출.
   - 송수신 시 현실감 있는 무전기 효과음(치-익, 삐빅 비프음) 적용.
4. **청취 누락 방지 음성 타임라인**:
   - 시끄러운 현장 소음으로 실시간 음성을 놓친 경우를 대비해, 최근 20건의 무전 음성 메시지를 채팅 타임라인처럼 1초 만에 다시 듣기(Replay) 제공.

## 3. 기술적 실현 방안 (Architecture)
- **방식**: WebRTC 또는 Supabase Realtime Broadcast + 초경량 Audio Blob (WebM/Opus) 파이프라인.
- **배터리 및 OS 제약 극복**:
  - 상시 스트리밍 대신 초단기 버스트 전송 방식으로 모바일 브라우저 메모리/배터리 소모 최소화.
  - 백그라운드 Web Audio API 및 Service Worker 알림 연동.

- **핵심 요구사항**:
  - 기본 4대 공용 채널 외에, 특정인(예: 사장+상무+부장 경영진 조, 또는 평택 고덕 현장 출고 전담 3인 조)만 콕 찍어 맞춤형 무전 채널을 즉석 생성.
  - 해당 채널에 초대된 사람에게만 탭이 노출되고 음성이 송수신되어 타 직원들의 업무 방해 및 소음 완벽 차단.
  - 당일 출고/작업이 끝나거나 필요가 없어지면 개설자(또는 관리자)가 원터치로 채널을 삭제/해체.

  - `[➕ 채널 생성]` 팝업 (채널명 입력 + 임직원 체크박스 선택).
  - `[🗑️ 채널 삭제]` 기능 (작업 종료 시 즉시 파기).

## 6. [확장 발상] 무전 음성 실시간 STT 변환 및 카카오톡형 채팅로그 타임라인 구축 (2026-09-04 13:25)
- **발상 제안**: 대표이사 (이수용 사장님)
- **문제의식 및 계기**:
  - 최근 20개 대화 오디오 다시듣기는 유용하나, 바쁜 현장이나 회의 중 스피커로 소리를 직접 듣기 어렵거나, 지나간 대화 중 특정 내용("몇 번 차 상차했더라?", "어느 현장이라고 했더라?")을 빠르게 눈으로 훑어보고 검색하기에는 음성 다시듣기만으로는 인지 비용이 큼.
  - 지나간 무전 대화를 텍스트(STT)로 자동 변환하여 **카카오톡 채팅창처럼 말풍선 로그로 조망하고, 필요할 때만 해당 말풍선의 [▶] 재생 버튼을 눌러 원본 음성을 듣는 하이브리드 음성-텍스트 타임라인**의 필요성 대두.
- **핵심 아키텍처 구상**:
  1. **단말 실시간 Web Speech API 연동 (비용 0원, 즉시성 100%)**:
     - 송신자가 PTT 버튼을 누르고 말하는 동안 마이크 녹음과 동시에 브라우저 내장 `webkitSpeechRecognition`(한국어 `ko-KR`)을 백그라운드로 구동.
     - PTT 버튼을 떼는 순간 녹음된 Audio Blob과 함께 실시간 전사된 `transcript: "3219번 2호차 상차 완료했습니다"` 텍스트가 페이로드에 동시 탑재되어 실시간 전송.
     - 별도의 유료 STT API 서버 비용 없이 0.1초 만에 텍스트가 수신자 화면에 즉시 표출됨.
  2. **말풍선 채팅로그 UI/UX**:
     - 무전기 화면 하단 또는 `[대화 기록]` 탭에 시간대순 카카오톡형 말풍선 로그 렌더링.
     - 각 말풍선 구성: `[발신자 이름/부서]` + `[전사된 텍스트]` + `[▶ 3초 음성 다시듣기 버튼]` + `[시간]`.
  3. **소음/회의실 무음 모드 지원**:
     - 스피커 방송을 끄고 무음으로 설정해 둔 사용자도 화면의 채팅로그 텍스트만 보고 실시간 현장 상황을 완벽히 파악 가능.
- **기대 효익**:
  - 시끄러운 건설 현장 소음으로 인해 음성이 묻히는 문제 완벽 해소.
  - 회의 중이거나 사무실에서도 무전 내용을 무음으로 즉시 파악.
  - 음성과 텍스트가 1:1로 결합된 완벽한 현장 업무 커뮤니케이션 감사 증빙 및 업무 히스토리 자산화.

## 7. [확장 발상] 수신자 상황별 3대 수신 모드 분기 (실시간 음성 / 비프 알림 / 완전 무음) 구상 (2026-09-04 13:35)
- **발상 제안**: 대표이사 (이수용 사장님)
- **문제의식 및 계기**:
  - 임직원의 근무 환경은 천차만별임: 현장 지게차 기사는 즉각적인 스피커 육성 방송이 필수지만, 사무실 내근직이나 다른 사람과 대화 중인 영업사원은 갑자기 스피커에서 타인의 목소리가 크게 울리면 당황스럽거나 곤란할 수 있음.
  - 또한 회의실이나 고객 대면 상담 중에는 비프음조차 울리면 안 되는 '완전 무음' 환경이 요구됨.
- **핵심 아키텍처 구상**:
  1. **수신 모드 3단계 분기 (`WalkieReceiveMode`)**:
     - **① `VOICE` (실시간 음성)**: 무전 도착 즉시 차임벨과 함께 상대방의 음성이 스피커로 자동 방송 (현장/작업 전용).
     - **② `BEEP` (비프 알림)**: 음성은 스피커로 출력하지 않고(무음성), 짧은 "삑"(차임) 소리와 가벼운 진동만 발생시켜 새로운 무전이 도착했음을 인지시키고 화면의 STT 텍스트 말풍선을 확인하게 유도 (사무실/내근 전용).
     - **③ `MUTE` (완전 무음)**: 어떤 소리도 일절 발생시키지 않고, 화면의 대화 타임라인에만 텍스트와 음성을 조용히 실시간 적재 (회의실/상담 전용).
  2. **원터치 3단 세그먼트 전환 UX**:
     - 무전기 헤더/LCD 상단에 `[🔊 실시간 음성] [🔔 비프 알림] [🔕 완전 무음]` 3단 토글 바를 배치하여 사용자가 현재 상황에 맞게 0.1초 만에 즉시 전환.
     - 사용자 선택값은 `localStorage`에 영구 보존되어 재접속 시에도 유지.
- **기대 효익**:
  - 사무실 직원, 현장 기사, 외근 영업, 경영진 등 모든 직무와 상황에서 거부감 없이 24시간 무전망에 상시 접속 유지 가능.
  - "삑" 소리 후 텍스트만 훑어보거나 필요할 때만 `[▶ 다시듣기]`를 누르는 완벽한 유연성 확보.

## 1. 발상의 배경 및 문제의식

### 1.1 현장 담당자의 인지 공백 문제
- 영업사원이 고객사와의 계약에 따라 출고/회수/교환 의뢰를 발행해도, 배차담당자나 출고/자산 관리자가 현장 이동, 장비 점검, 운전 등으로 인해 핸드폰 화면을 실시간 응시하지 못하면 **의뢰가 수십 분~수 시간 동안 방치되는 리드타임 지연**이 발생할 수 있음.
- 따라서 **"담당자가 [접수/배정] 조치를 취할 때까지 5분 간격으로 부드럽고 끈질기게 업무 발생 상황을 인지시키는 장치"**가 필수적임.

### 1.2 대상 4대 핵심 업무 사건 (Target 4 Events)
1. **출고 의뢰 (Outbound Request)**: 영업 ➔ 배차/출고팀
2. **입고/회수 의뢰 (Inbound/Return Request)**: 영업/현장 ➔ 배차/주기장
3. **배차 요청 (Truck Dispatch Order)**: 영업/관리 ➔ 배차담당
4. **장비 할당 요청 (Asset Allocation Request)**: 영업/배차 ➔ 주기장 자산관리자

## 2. 모바일 환경별 최적 인지 방식 비교 및 판단

| 구분 | 인지 방식 | 장점 | 단점 / 기술적 제약 | 적합도 |
| :--- | :--- | :--- | :--- | :--- |
| **방식 1** | **포그라운드 인앱 사운드+진동+점멸 HUD** | 비용 0원, 즉시 구현 가능, 앱 화면 보고 있을 때 가장 즉각적 인지 | 화면이 잠겨 있거나 타 앱 전환 시 폰 절전 모드로 타이머 멈춤 | **★★★★★ (앱 활성 시 필수)** |
| **방식 2** | **PWA Web Push 알림 (Service Worker)** | 화면 꺼짐/잠금 상태에서도 상단 알림 바 + 진동 노출, 비용 0원 | 사용자의 브라우저 알림 승인 필요, iOS는 홈화면 추가 PWA 모드 권장 | **★★★★★ (백그라운드 필수)** |
| **방식 3** | **카카오 알림톡 / SMS 5분 주기 발송** | 폰 기종 무관 100% 도달, 앱 미실행 상태에서도 수신 | 건당 8~15원 비용 발생, 미접수 시 5분마다 반복 발송 시 비용 과다 | **★★☆☆☆ (비용 및 피로도 문제)** |
| **방식 4** | **모바일 무전기 TTS 음성 브로드캐스트** | 음성으로 "송도 현장 출고 1건 미접수 대기 중" 자동 방송 | 전사 공용 채널 시 타 부서 청각 피로, 전용 채널 분리 필요 | **★★★☆☆ (보조 수단)** |

## 3. 권고 하이브리드 아키텍처 (Hybrid Notification Architecture)

### 3.1 1단계: 포그라운드 (앱 켜짐/사용 중) ➔ [상단 플로팅 카운트다운 HUD + 사운드 + 햅틱]
- 앱 최상단에 상시 고정되는 "🚨 미접수 의뢰 N건 (대기시간 05:20)" 펄스 애니메이션 바.
- 5분(300초) 동안 접수되지 않으면 Web Audio API를 통해 소프트 차임벨(2음계)과 navigator.vibrate([200, 100, 200]) 햅틱 진동 자동 트리거.
- 클릭 시 해당 ToDo 팝업으로 즉시 연결하여 [접수] 또는 [배정] 원클릭 완결.

### 3.2 2단계: 백그라운드 (화면 꺼짐 / 주머니 속) ➔ [Service Worker Web Push]
- 서버(Cloudflare Worker Cron 또는 Supabase Edge Function)가 5분마다 미접수 건을 검사하여, 담당자 기기로 Web Push 전송:
  - "🚚 [출고 미접수 알림] 포스코이앤씨 2대 출고 의뢰가 5분째 대기 중입니다. 지금 확인하세요."

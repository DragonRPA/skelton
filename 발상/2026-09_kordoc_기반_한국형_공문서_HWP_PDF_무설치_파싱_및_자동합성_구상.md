## 1. 발상 배경 및 문제 의식 (Inception Context)

1. **지독한 한국형 문서 포맷 파편화**:
   - 렌탈 현장 및 대외 거래처, 관공서, 대기업 건설사는 여전히 HWP, HWPX, 복합 표 PDF, 스캔본 이미지를 기본 소통 규격으로 고수함.
   - 기존에는 HWP/HWPX 처리를 위해 Windows 환경의 한컴오피스 오토메이션(COM), 가상 프린터 드라이버, 무거운 LibreOffice 변환기 등에 의존하거나, 엑셀 COM 엔진을 띄워 PDF로 출력하는 방식에 의존함.
   - 이로 인해 **OS 종속성(Windows 강제), 백그라운드 프로세스 행(Hang) 및 리소스 누수 방어 부담, 클라우드/리눅스/서버리스 환경 배포 불가**라는 구조적 병목이 상존함.

2. **클라우드 비전 API의 비용 및 레이턴시**:
   - 사업자등록증, 통장사본, 제원표 등 이미지/스캔본 서류 처리를 위해 외부 클라우드 Vision AI(Gemini, Claude 등)를 호출하면서 건당 과금과 네트워크 전송 지연이 누적됨.

3. **kordoc 오픈소스 발견과 패러다임 전환**:
   - 한컴/MS 오피스 설치 없이 순수 TypeScript(Node.js 20+) 기반으로 HWP(3.x/5.x), HWPX, PDF, XLSX, DOCX, 이미지를 0.04초대에 양방향 변환·생성·렌더링하는 `kordoc`(v4.15)의 등장.
   - 글로벌 PDF 벤치마크 1위(0.935점) 및 공문서 실측 데이터셋 13,041개 검증 통과라는 압도적 무결성 확인.

## 3. 핵심 5대 아키텍처 구상 (5 Core Architecture Pillars)

### ① 📑 [계약/서류팩] 탈(脫) COM HWPX 누름틀 고속 채우기 및 직인 자동 날인
- 정품 계약서, 반입전체크리스트, 안전점검결과서를 HWPX 누름틀(`CLICK_HERE`) 서식으로 표준화.
- `kordoc.fillForm(template, data, "hwpx-preserve")`을 통해 원본 서식을 1바이트도 건드리지 않고 0.05초 만에 데이터 바인딩.
- `kordoc.placeSealHwpx()`를 연동하여 `(인)` 또는 `서명 또는 인` 위치에 법인 투명 직인 PNG를 오차 없이 부유 배치.
- Linux 컨테이너 및 Node.js 백엔드에서 한컴 없이 실물 인쇄 품질의 HWPX/PDF 자동 발행.

### ② 👁️ [고객등록/재무] 내장 로컬 CPU PP-OCRv5 기반 100% 무비용 자동 등록
- 사업자등록증 및 통장사본 사진/스캔 PDF 처리 시 외부 유료 API 호출 전단에 `kordoc`의 로컬 OCR(완성형 11,172자 전량 내장)을 1차 파서로 배치.
- API 과금 $0 달성, 고객 개인정보의 외부 클라우드 유출 원천 방지, 0.4초대 로컬 판독 완료.

### ③ ⚖️ [채권/법무] 연체 고객 출고금지처분 및 '내용증명·최고장' 원클릭 발행
- 연체 미수금 대장의 데이터를 바탕으로 `kordoc.markdownToHwpx(md, { gongmun: { preset: "official" } })`를 호출.
- 우체국 e-그린우편 및 내용증명 규격(항목부호 8단계, 표 위계 음영, "끝." 마크, 직인 날인)을 100% 만족하는 공문서 즉시 생성.

### ④ 📚 [기술/정비] 장비 정비 매뉴얼 라이브러리 및 RAG 지식 베이스
- 수백 페이지의 고소작업대(Genie, Skyjack 등) 2단 컬럼 PDF 매뉴얼과 복합 제원표를 `kordoc --format chunks`로 파싱.
- 텍스트 섞임 없는 XY-Cut 순서 복원 및 헤딩 브레드크럼 기반 구조 청킹으로 사내 정비 챗봇의 검색 정확도 극대화.

### ⑤ 🤖 [AI 에이전트] Antigravity 전용 17대 문서 조작 도구(MCP) 상시 연동
- `npx -y kordoc setup`을 통해 개발 환경 및 사내 에이전트에 MCP 서버 상시 탑재.
- AI 페어 프로그래머 및 에이전트가 고객사 발주서, 견적서, 관공서 서식을 직접 읽고(`parse_document`), 서식을 채우고(`fill_form`), 변경 내역을 신구대조(`compare_documents`)하도록 지원.

## 4. 전사 시스템 개발 표준 헌장 준수 기준

1. **최우선 사명 준수 (헌장 1.1: 최대 편익)**:
   - 복잡한 오피스 프로그램 설치 및 라이선스 비용 제거, 수기 서류 작성 95% 감축으로 임직원에게 압도적 편익 제공.

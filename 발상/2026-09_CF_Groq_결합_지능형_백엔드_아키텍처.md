## 1. 발상 배경

이에 따라 "Cloudflare의 글로벌 엣지 런타임(Workers, DO, Queues, R2)과 Groq LPU의 초고속 추론 엔진(단일 칩 초당 300~800 토큰 생성, JSON Schema 강제 모드)을 백엔드로 결합하여 어떤 전사 시스템을 실현할 수 있는가?"라는 본질적 질문에서 발상이 시작되었다.

   - `SPEC-VOICE-02`: 무전 전사문 ➔ Groq Llama-3.3-70B 기반 비정형 발화 분석 ➔ 배차/AS 의뢰 슬롯 자동 추출 및 ERP 초안(Draft) 발행.
   - `SPEC-VOICE-03`: Cloudflare Vectorize + Groq 70B 결합 현장 고소작업대 82개 모델 고장코드 음성 질의 RAG 엔진.
2. **비전/검수 도메인**:
   - `SPEC-VISION-01`: 상/하부 조종기 7-Segment LED 및 경고등 사진 ➔ R2 버퍼 ➔ Groq Llama-3.2-Vision 1.1초 내 고장코드/응급조치 자동 진단.
   - `SPEC-VISION-02`: 출고 전 4면 사진 ➔ CF Queues 분산 ➔ Groq Vision 12대 필수 안전스펙 전수 검수.
   - `SPEC-VISION-03`: 반납 입고 사진 vs 출고 당시 R2 원본 사진 1:1 시계열 Visual Diff ➔ 고객 과실 파손 정밀 판정.
3. **ERP/데이터 도메인**:
   - `SPEC-DATA-01`: 비정형 통장 거래내역 ➔ Groq Llama-3.3-70B 추론 ➔ 미수 청구서 다대다 분할 대사 및 PostgreSQL RPC 원자적 수납 커밋.
   - `SPEC-DATA-02`: 월말 수천 건 운송료 청구 엑셀 ➔ CF Queues 청크 분할 ➔ 대차대조식(`청구 = 확정 + 반려 | 차액 ₩0`) 100% 무결성 검증.
   - `SPEC-DATA-03`: 자연어 질의 ➔ AST 화이트리스트 샌드박스 ➔ 읽기 전용 PostgreSQL 안전 조회 게이트웨이.
4. **엣지 인프라 도메인**:
   - `SPEC-INFRA-01`: Durable Objects 기반 전역 토큰 버킷 레이트 리미터 & 3-State 서킷 브레이커 (Workers AI 페일오버).
   - `SPEC-INFRA-02`: Claim-Check 패턴 기반 대용량 R2 격리 및 Queues 지연 흡수 배치 엔진.
   - `SPEC-INFRA-03`: 오프라인 IndexedDB Outbox ➔ 네트워크 복귀 시 UUID 멱등성 보장 무누락 리플레이.

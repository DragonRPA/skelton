## 1. 핵심 구상 배경 (Why UIA?)

비전(이미지 매칭) 방식은 직관적이지만 아래와 같은 본질적 제약이 존재함:
1. 화면 해상도/배율/테마/글꼴 변경 시 재캡처 필요성
2. 화면에 가려지거나 스크롤 밖에 있는 요소 조작 불가 (반드시 전면에 보여야 함)
3. 마우스 커서를 직접 움직여야 하므로 작업자의 백그라운드 멀티태스킹 간섭

Windows의 표준 접근성 트리인 **UI Automation (UIA COM API / `UIAutomationCore.dll`)**을 Pure C Native 엔진에 연동하면, 이미지 없이도 컨트롤의 구조적 식별자(`Name`, `AutomationId`, `ControlType`, `Pattern`)를 직접 호출하여 0.1ms 수준의 무침습 제어가 가능해짐.

---

## 2. UIA 접근 가능 5대 핵심 기능

### ① 텍스트/라벨 기반 무이미지 즉시 제어 (Zero-Image Instant Control)
- 이미지 캡처 없이 `"다음"`, `"설치"`, `"동의함"`, `"확인"` 텍스트만으로 버튼 즉시 타격.
- 다크모드, 해상도 변경, 테마 변경에도 100% 무결점 보장.

### ② 스마트 설치 마법사 자동 통과 (Auto-Wizard Engine)
- 설치 프로그램(Inno Setup, InstallShield, NSIS, MSI 등)의 UI 패턴을 자동 감지:
  - 약관 체크박스(`ControlType_CheckBox` + "동의") 자동 체크 (`TogglePattern`)
  - 다음/설치 버튼(`ControlType_Button` + "다음"/"Next") 연쇄 통과 (`InvokePattern`)
  - 설치 완료 대기 및 닫기 자동화

### ③ 화면 텍스트/상태값 비침습적 직독 (Zero-OCR Instant Text Extraction)
- 무거운 OCR 엔진 없이, UIA 트리의 `ValuePattern`, `TextPattern`, `Name`을 통해 화면의 에러 메시지, 라이선스 번호, IP 주소, 버전 정보를 0.001초 만에 100% 정확하게 텍스트 추출.
- 상태 텍스트 기반 분기(`STEP_UIA_BRANCH`) 처리.

### ④ 백그라운드/비활성 창 무침습 제어 (Background Non-Intrusive Control)
- 창을 활성화(`SetForegroundWindow`)하거나 마우스 커서를 움직이지 않고, 백그라운드 상태에서 직접 `Invoke()` 및 `SetValue()` 주입.
- 작업자가 다른 PC 작업을 진행하는 중에도 백그라운드에서 완벽히 셋업 매크로 동작.

### ⑤ 실시간 UI 요소 스파이/피커 (Live UIA Element Inspector)
- 화면 위에 마우스를 올리면 해당 컨트롤의 UIA 속성(`AutomationId`, `Name`, `ClassName`, `지원 패턴`)을 실시간 스니핑하여 매크로 스텝으로 원클릭 등록.

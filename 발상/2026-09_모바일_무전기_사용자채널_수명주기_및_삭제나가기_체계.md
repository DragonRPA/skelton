## 1. 배경 및 문제 진단

### 1.1 현재 시스템의 결함 (채널 영구 누적 문제)
- 현재 무전기 서비스는 `createChannel`(새 채널 개설)과 `inviteMembers`(사원 초대)만 구현되어 있고, **`deleteChannel`(채널 삭제) 및 `leaveChannel`(채널 나가기) 기능이 부재**함.
- 이로 인해 테스트나 임시 현장 소통을 위해 만든 채널이 로컬 스토리지(`walkie_channels_v2`)와 전사 브로드캐스트망에 영구 잔존하여 채널 탭이 과밀해지는 문제 발생.

---

## 2. 권한별 채널 수명주기(Lifecycle) 3대 표준 설계

### 2.1 [개설자/방장 권한]: 명시적 [채널 삭제] 트리거
- 조건: `!ch.isDefault && ch.createdById === currentUser.id` (본인이 개설한 사용자 정의 채널)
- UI: 채널 서브헤더 우측에 붉은색 `[채널 삭제]` 버튼 노출.
- 동작:
  1. 개설자가 삭제 버튼 터치 시 확인 모달 표출.
  2. 전사 실시간 메타 브로드캐스트(`channel_deleted`) 발송.
  3. 온라인 참가자 전원의 기기에서 해당 채널 즉시 파기 및 로컬 스토리지 삭제.
  4. 해당 채널을 듣고 있던 모든 참가자는 기본 채널(`CH-01 출고배차`)로 자동 안전 복귀.

### 2.2 [일반 참여자 권한]: [채널 나가기] 트리거
- 조건: `!ch.isDefault && ch.createdById !== currentUser.id && ch.memberIds.includes(currentUser.id)`
- UI: 채널 서브헤더 우측에 `[채널 나가기]` 버튼 노출.
- 동작:
  1. 참여자가 나가기 터치 시 `ch.memberIds`에서 본인 ID 제거.
  2. 본인 기기 채널 목록에서 즉시 제거되고 기본 채널(`CH-01`)로 복귀.
  3. 메타 브로드캐스트(`channel_updated`)로 다른 참여자들에게 참여자 수 차감 동기화.

### 2.3 [자동 소멸 트리거]: 참여자 0명 고아 채널 가비지 컬렉션
- 참여자가 차례로 나가서 `ch.memberIds.length === 0`이 되는 순간, 시스템이 해당 채널을 자동으로 영구 소멸 처리.

### 2.4 [기본 채널 영구 불변 보호]
- `CH-01 출고배차`, `CH-02 현장AS`, `CH-03 영업` 등 전사 기본 채널(`isDefault: true`)은 삭제/나가기 버튼 자체를 숨겨 영구 보존.

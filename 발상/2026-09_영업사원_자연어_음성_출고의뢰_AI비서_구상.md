## 1. 발상 배경 및 도메인 동기 (Problem & Context)

> **"우리는 음성입력과, STT 처리의 가능성을 확인했어. 그렇다면 영업사원이 출고의뢰를 음성으로 입력할 방법을 제시해 줄 수 있지 않을까? 어떤 설계가 가능하지? 대신 조금 느리더라도 순수 음성만으로 편리하게 입력을 도와주고 싶어."**
> — 이수용 사장님 (2026-09-04)

### 🚜 현장 영업사원의 현실적 고충
1. **모바일 폼 입력의 높은 허들**:
   - 건설 현장 미팅 직후, 혹은 차량 운전 중 좁은 스마트폰 화면에서 거래처 검색, 현장 선택, 날짜/시간 드롭다운, 장비 규격/수량, 현장 소장님 연락처를 일일이 손가락으로 타이핑하는 것은 극도로 번거롭고 안전상 위험함.
2. **현업의 실제 소통 방식**:
   - 영업사원은 사무실 출고 담당자나 밴드에 전화를 걸어 구어체로 두서없이 쏟아냄:
     *"어 나 이과장인데, 내일 아침 8시까지 삼성물산 평택 P4 복합동 현장에 32피트 두 대랑 19피트 한 대 넣어줘. 현장 박소장님 010-8888-9999로 기사 번호 넘겨주고, 바닥 보양판 꼭 챙겨가라고 해."*
3. **최대 편익의 사명 (헌장 1.1)**:
   - "조금 느리더라도(3~5초의 AI 추론 지연이 있더라도) 순수 음성만으로 편리하게 입력을 종결짓는 시스템"을 구축하여, 영업사원의 현장 조작 노력을 0에 가깝게 줄이고 배차/출고 실수(무누락)를 방지하는 것이 최상의 효익임.

## 2. 핵심 아키텍처 및 4단계 파이프라인 구상

```
┌─────────────────┐     🎙️ 자연어 음성 발화 (운전 중/현장에서 한 번에 말하기)
│ 1. 음성 수신    │     "내일 아침 8시 삼성물산 고덕 P4에 32피트 2대, 19피트 1대..."
│ (STT Intake)    │     ➔ Web Speech API / 스트리밍 한글 음성 텍스트화
└────────┬────────┘
         ▼
┌─────────────────┐     🧠 초경량/서버리스 LLM (Gemini Flash / Qwen)
│ 2. 엔티티 추출  │     ➔ 자연어 ➔ JSON 스키마 변환
│ (Schema Parser) │     { 고객사: '삼성물산', 현장: '고덕 P4', 납품일: '2026-09-05 08:00', ... }
└────────┬────────┘
         ▼
┌─────────────────┐     🏛️ ERP 단일진실(SSOT) 매칭 및 정규화
│ 3. 마스터 매핑  │     ➔ 고객사 DB 1:1 바인딩 (`CUST-0012`)
│ (DB Resolution) │     ➔ 현장 등록 주소 및 옵션/보양 100% 자동 상속 (헌장 2.2)
└────────┬────────┘
         ▼
┌─────────────────┐     📢 음성 브리핑(TTS) & 원터치 최종 확정
│ 4. 대화형 검증  │     "삼성물산 고덕 P4 현장으로 내일 오전 8시, 32ft 2대, 19ft 1대 의뢰를
│ (Confirmation)  │      인식했습니다. 등록할까요?" ➔ [네, 등록해주세요] ➔ 스마트 출고 접수 종결!
└─────────────────┘
```

## 3. 세부 기술 구현 요소

1. **클라이언트 (PWA 웹앱)**:
   - 모바일 무전기 모달과 유사한 인체공학적 마이크 인터페이스 (`[🎙️ 음성 출고의뢰]`).
   - 발언 중 실시간 텍스트 버블(`liveTranscript`) 시각화.
2. **AI 파서 (NLP Entity Extractor)**:
   - 건설/렌탈 특화 프롬프트: '32피트' ➔ '3246', '19피트' ➔ '1930', '배차기사 번호' ➔ '기사직통 전달' 등 현장 도메인 은어 완벽 해석.
3. **누락 필드 대화형 질의 (Missing Field Fallback)**:
   - 만약 납품 날짜나 연락처를 빠뜨리고 말했다면 AI가 스스로 부족한 항목을 질문:
     *"현장 담당자 연락처가 빠졌습니다. 전화번호를 말씀해주세요."*
4. **결과 반영**:
   - `MobileDispatchOrderCreate.tsx` 폼에 마법처럼 100% 자동 채움(Auto-Fill)되어, 눈으로 카드 확인 후 최종 터치 또는 음성으로 의뢰 발행.

## 4. 기대 효익
- **입력 소요 시간**: 기존 2~3분(수동 타이핑/셀렉트) ➔ **15초(말 한마디로 종결)**.
- **오타 및 누락 제로화**: 현장 주소와 담당자 정보가 ERP 마스터로부터 자동 상속되어 배차 오류 원천 차단.
- **영업 생산성 극대화**: 운전 중이나 현장 이동 중에도 즉시 업무 완결.

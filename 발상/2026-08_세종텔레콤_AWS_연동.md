# 발상: 세종텔레콤 + AWS 연동 프로토타입 및 아키텍처 준비 (2026-08-24 18:10)

## 1. 맥락
현재 프로젝트(`Space_consult_assist`)에 당장 적용되지는 않지만, 차후 세종텔레콤의 비즈메시지(알림톡, SMS, LMS 등) 혹은 관련 서비스를 AWS 환경에서 연동하기 위한 준비 단계로 프로토타입을 구상함.

## 2. 핵심 내용
- **AWS 환경에서의 API 통신 한계점 극복**: 세종텔레콤 API 서버는 보안상 허용된 IP(화이트리스트)からの 요청만 수락하는 경우가 많음. 서버리스 환경(AWS Lambda)은 동적 IP를 가지므로, **VPC 내부에 Lambda를 배치하고 NAT Gateway(Elastic IP 포함)를 통해 고정 공인 IP로 아웃바운드 통신**을 하는 인프라 구성이 필수적으로 요구됨.
- **메시지 전송 폴백(Fallback) 처리**: 카카오 알림톡 발송 실패 시(예: 카카오톡 미설치 고객 등), 자동으로 일반 SMS/LMS로 전환 발송하는 로직이 백엔드(Lambda) 단에 구현되어야 함.
- **웹훅(Webhook)을 통한 결과 수신**: 전송 성공/실패 여부를 비동기로 수신하기 위해 AWS API Gateway + Lambda를 구성하여 세종텔레콤 측의 콜백을 받아 DB(DynamoDB 또는 RDS)에 기록하는 파이프라인 설계 필요.

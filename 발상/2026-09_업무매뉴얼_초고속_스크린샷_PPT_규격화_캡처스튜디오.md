## 1. 발상 배경 및 사장님의 핵심 요구사항 (Core Need)

> **"나는 업무매뉴얼 제작을 위해서 아주 많은 스크린샷을 찍고 PPT에 붙여넣기를 반복 처리해야하는데, 이작업을 도와줄 도구를 먼저 하나 만들고 싶어. 스크린샷 범위지정, 스크린샷 단축키(즉시 클립보드로 이미지 이동) 파워포인트 위에서 ctrl + v 했을때 항상 같은 크기가 되도록 캡처 시점에 resize 되도록 하면 좋겠어. 내가 생각하지 못한 더 좋은 아이디어가 있으면 제안해줘."**
> — 이수용 사장님 (2026-09-09)

### 🎯 문제의 본질 (Pain Points)
1. **끝없는 반복 노동 (Ctrl+C, Alt+Tab, Ctrl+V, Resize, Reposition 무한 루프)**:
   - 매뉴얼 1개 작성 시 50~200장의 스크린샷이 소요됨.
   - 드래그 영역마다 크기/비율이 제각각이라, PPT 슬라이드에 붙여넣을 때마다 마우스로 모서리를 잡고 크기를 줄이거나 늘려야 함.
2. **슬라이드 간 시각적 통일성 부재**:
   - 수동 리사이즈로 인해 슬라이드마다 캡처 화면 폭과 위치가 미세하게 어긋나 매뉴얼 완성도가 저하됨.
3. **부수적 수작업 (스텝 번호 원형 도형, 마우스 커서 부재, 화살표/강조 박스)**:
   - 캡처 후 PPT에서 "①, ②, ③" 번호 도형이나 빨간 테두리 사각형을 손으로 얹는 데 전체 시간의 60% 이상이 낭비됨.

## 2. 해결 아키텍처 및 확장 아이디어 (7 Core Ideas)

### 1️⃣ [핵심 1] PPT 슬라이드 최적화 '자동 리사이즈 & 캔버스 정규화'
- **방식 A (가로폭 고정 정규화 - Fixed Width Lanczos)**:
  - 캡처된 영역 종횡비를 유지하면서, PPT 슬라이드 본문 폭(예: 960px 또는 1200px)으로 초고화질(Lanczos) 자동 리사이즈.
- **방식 B (슬라이드 프레임 고정 패딩 - Fixed Canvas Frame)**:
  - 지정한 해상도(예: 1280x720 16:9) 캔버스 중앙에 캡처 이미지를 정렬하고 여백을 투명/단색으로 채워, PPT에 붙여넣으면 100% 동일한 위치와 크기로 완벽 안착.

### 2️⃣ [핵심 2] 제로 딜레이 클립보드 직결 (Instant Clipboard Feed)
- 마우스 드래그를 떼는 순간 찰칵 효과음과 함께 클립보드에 즉시 복사. 별도 '복사'나 '저장' 버튼 클릭 행위 전면 배제.

### 3️⃣ [확장 1] 원클릭 자동 증가 스텝 넘버링 마커 (Auto-Increment Step Badge)
- 캡처 영역 지정 직후 마우스 클릭 시 ①, ②, ③ 번호 뱃지가 해당 좌표에 자동 합성.

### 4️⃣ [확장 2] 마우스 커서 합성 & 원클릭 레드 포커스 박스
- 윈도우 기본 캡처에서 누락되는 마우스 커서를 이미지에 자연스럽게 합성.
- 강조할 버튼이나 입력창에 빨간색 강조 테두리(2px)를 즉시 부여.

### 5️⃣ [확장 3] 민감정보 원터치 블러/모자이크 (Privacy Mask)
- 마우스 우클릭 드래그로 고객명, 계좌번호, 전화번호를 즉시 블러 처리.

### 6️⃣ [확장 4] 로컬 세션 자동 아카이빙 (Step Auto-Backup)
- 클립보드 복사와 동시에 작업 폴더에 `Step_001.png`, `Step_002.png`로 무손실 자동 저장하여 유실 방지.

### 7️⃣ [확장 5] PowerPoint COM 직결 모드 (Direct PPT Slide Ingestion - 끝판왕)
- PPT에서 `Ctrl + V` 누를 필요도 없이, 캡처 완료 즉시 열려 있는 PowerPoint의 새 슬라이드에 이미지와 제목 레이아웃을 자동 생성.
